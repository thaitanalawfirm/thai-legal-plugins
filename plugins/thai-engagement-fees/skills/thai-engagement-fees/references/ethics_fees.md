# ethics_fees.md — กรอบมรรยาททนายความเรื่องค่าวิชาชีพ

อ่านไฟล์นี้ก่อนสรุปข้อตกลงค่าวิชาชีพทุกครั้ง

> ⚠️ กรอบเรื่องค่าวิชาชีพอ้างอิง **ข้อบังคับสภาทนายความว่าด้วยมรรยาททนายความ** เป็นหลัก
> ให้ตรวจสอบตัวบทฉบับปัจจุบันเสมอ ไฟล์นี้ให้กรอบแนวคิด ไม่ใช่ตัวบทเต็ม และไม่ใช่การตีความ
> ผูกมัด — เมื่อไม่แน่ใจ ให้ทนายผู้รับผิดชอบตรวจสอบข้อบังคับโดยตรง

---

## สารบัญ
1. หลักความเหมาะสมของค่าวิชาชีพ
2. ข้อควรระวังเรื่องค่าตอบแทนตามผล/ส่วนแบ่ง
3. ความโปร่งใสและความเป็นธรรม
4. สิ่งที่ต้องตรวจก่อนสรุปข้อตกลง

---

## 1. หลักความเหมาะสมของค่าวิชาชีพ

ค่าวิชาชีพควรเหมาะสมและอธิบายได้ พิจารณาจากปัจจัยเช่น:
- ความยากและความซับซ้อนของงาน
- เวลาและความชำนาญที่ต้องใช้
- มูลค่าของเรื่อง/ทุนทรัพย์
- ความรับผิดชอบและความเสี่ยงของงาน
- ความเร่งด่วน
ค่าวิชาชีพที่สูงเกินสมควรหรือไม่เป็นธรรมอาจขัดมรรยาทและก่อข้อพิพาท

## 2. ข้อควรระวังเรื่องค่าตอบแทนตามผล/ส่วนแบ่ง

- ข้อตกลงที่ทนาย **เข้ามีส่วนได้เสียในผลของคดีโดยตรง** โดยเฉพาะ **การแบ่งเอาส่วนจากทรัพย์สิน
  ที่เป็นมูลพิพาท** มีกรอบและข้อจำกัดทางมรรยาทที่เข้มงวด
- รูปแบบนี้ **อาจทำไม่ได้หรือทำได้จำกัด** ขึ้นกับข้อบังคับมรรยาทฉบับปัจจุบันและประเภทคดี
- **ก่อนเสนอรูปแบบตามผล/ส่วนแบ่ง ต้องตรวจข้อบังคับมรรยาทฉบับปัจจุบัน** และให้ทนายผู้รับผิดชอบ
  วินิจฉัยว่าทำได้หรือไม่ในกรณีนั้น — อย่าเสนอแบบฟันธงว่าทำได้โดยไม่ตรวจ

## 3. ความโปร่งใสและความเป็นธรรม

- เปิดเผยวิธีคิดค่าวิชาชีพและค่าใช้จ่ายให้ลูกความเข้าใจก่อนตกลง
- ไม่ซ่อนค่าใช้จ่ายหรือใช้ถ้อยคำกำกวมที่ทำให้ลูกความเข้าใจผิด
- ไม่ผูกค่าวิชาชีพกับการรับประกันผลคดี (การรับประกันผลขัดหลักวิชาชีพ)
- ทำข้อตกลงเป็นลายลักษณ์อักษรเพื่อความชัดเจนของทั้งสองฝ่าย

## 4. สิ่งที่ต้องตรวจก่อนสรุปข้อตกลง

- [ ] ค่าวิชาชีพเหมาะสมกับงานและอธิบายได้
- [ ] ไม่มีการรับประกันผลผูกกับค่าวิชาชีพ
- [ ] หากใช้แบบตามผล/ส่วนแบ่ง — ตรวจข้อบังคับมรรยาทฉบับปัจจุบันและให้ทนายผู้รับผิดชอบวินิจฉัย
- [ ] เปิดเผยและโปร่งใสเรื่องค่าวิชาชีพและค่าใช้จ่าย
- [ ] เป็นธรรมต่อลูกความ ไม่เอาเปรียบ
- [ ] ทำเป็นลายลักษณ์อักษร

## สรุป
ค่าวิชาชีพต้อง **เหมาะสม โปร่งใส เป็นธรรม และอยู่ในกรอบมรรยาท** ระวังเป็นพิเศษกับรูปแบบ
ตามผล/ส่วนแบ่งซึ่งมีข้อจำกัด — ตรวจข้อบังคับมรรยาทฉบับปัจจุบันและให้ทนายผู้รับผิดชอบวินิจฉัย
ก่อนใช้เสมอ
