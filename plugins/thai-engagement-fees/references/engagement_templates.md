# engagement_templates.md — แม่แบบหนังสือว่าจ้าง

ใช้แม่แบบเหล่านี้เป็นโครง ปรับตามรูปแบบค่าวิชาชีพและประเภทงาน

> ทำเครื่องหมาย [....] ทุกจุดที่ต้องเติม · ทุกฉบับเป็นร่างให้ทนายผู้รับผิดชอบตรวจรับรอง

---

## 1. แม่แบบหนังสือว่าจ้าง (ทั่วไป)

```
                                            วันที่ [....]

หนังสือว่าจ้างที่ปรึกษากฎหมาย/ทนายความ

ระหว่าง  [ชื่อสำนักงาน/ทนายความ] ("สำนักงาน")
และ      [ชื่อลูกความ] ("ลูกความ")

1. ขอบเขตงาน
   สำนักงานตกลงรับดำเนินการ [ระบุงาน] ครอบคลุม [ชั้น/ขั้นตอน]
   สิ่งที่ไม่รวมในขอบเขตนี้: [ระบุ]

2. ค่าวิชาชีพ
   รูปแบบ: [รายชั่วโมง/เหมาจ่าย/ตามชั้นศาล/retainer]
   อัตรา: [....]
   สิ่งที่อัตรานี้ครอบคลุม: [....]

3. ค่าใช้จ่าย (Disbursements)
   ลูกความรับผิดชอบค่าใช้จ่ายตามจริง ได้แก่ [ค่าธรรมเนียมศาล ค่าผู้เชี่ยวชาญ ค่าเดินทาง ฯลฯ]
   แยกต่างหากจากค่าวิชาชีพ

4. การวางเงินล่วงหน้าและการชำระเงิน
   เงินวางล่วงหน้า: [....]
   รอบวางบิล: [....]   กำหนดชำระ: ภายใน [....] วันนับแต่วางบิล

5. หน้าที่ของลูกความ
   ให้ข้อเท็จจริงและเอกสารที่ถูกต้องครบถ้วนและทันเวลา และชำระค่าตอบแทนตามที่ตกลง

6. การรักษาความลับ
   สำนักงานจะรักษาความลับข้อมูลของลูกความตามหน้าที่ทางวิชาชีพ

7. การเปลี่ยนแปลงขอบเขตงาน
   หากงานขยายเกินขอบเขตข้อ 1 จะตกลงขอบเขตและค่าวิชาชีพเพิ่มเป็นลายลักษณ์อักษรก่อนดำเนินการ

8. การยุติการว่าจ้าง
   [สิทธิยุติของทั้งสองฝ่าย ผลต่อค่าวิชาชีพสำหรับงานที่ทำไปแล้ว การคืนเงินวางส่วนที่เหลือ
   และการส่งคืนเอกสาร]

9. ข้อกำหนดทั่วไป
   [กฎหมายที่ใช้บังคับ การระงับข้อพิพาท ช่องทางติดต่อ]

         ลงชื่อ ..................... สำนักงาน/ทนายความ
         ลงชื่อ ..................... ลูกความ
         วันที่ ..............
```

## 2. แม่แบบสัญญาจ้างว่าความ (เน้นงานคดี) — ส่วนที่ต่างจากข้างบน

```
ข้อ 1 คดี/เรื่อง: [ระบุคดี คู่ความ ศาล]
ข้อ 2 ขอบเขต: ว่าความในชั้น [ศาลชั้นต้น / อุทธรณ์ / ฎีกา / บังคับคดี]
              (ระบุชัดว่ารวม/ไม่รวมชั้นใด)
ข้อ 3 ค่าวิชาชีพ: [เหมาตามชั้นศาล หรือรูปแบบอื่น] แยกตามชั้นพร้อมเงื่อนไขการไปต่อแต่ละชั้น
ข้อ 4 ค่าธรรมเนียมศาลและค่าใช้จ่าย: ลูกความรับผิดชอบ (ค่าขึ้นศาลคำนวณตามตารางท้าย ป.วิ.พ.)
[ข้ออื่นเช่นเดียวกับแม่แบบทั่วไป]
```

## 3. แม่แบบเปรียบเทียบรูปแบบค่าวิชาชีพ (สำหรับเสนอลูกความ)

```
ข้อเสนอค่าวิชาชีพ — เรื่อง [....]

ทางเลือกที่ 1: [รูปแบบ] — อัตรา [....]
   เหมาะเมื่อ: [....]   ข้อดี: [....]   ข้อควรพิจารณา: [....]

ทางเลือกที่ 2: [รูปแบบ] — อัตรา [....]
   เหมาะเมื่อ: [....]   ข้อดี: [....]   ข้อควรพิจารณา: [....]

ค่าใช้จ่ายที่ลูกความรับผิดชอบ (ทุกทางเลือก): [....]
```

---

## ข้อควรจำ
- เลือกแม่แบบตามประเภทงาน (ทั่วไป/คดี) และรูปแบบค่าวิชาชีพ
- ระบุขอบเขตและสิ่งที่ไม่รวมให้ชัด แยกค่าวิชาชีพ/ค่าใช้จ่าย
- ค่าธรรมเนียมศาลคำนวณจากตารางจริงในคลัง ไม่เดา
- ตรวจกรอบมรรยาท (`ethics_fees.md`) ก่อนสรุป
- ปิดท้ายด้วย "ข้อสังเกตจากทนาย" และระบุว่าเป็นร่างให้ทนายผู้รับผิดชอบรับรอง
