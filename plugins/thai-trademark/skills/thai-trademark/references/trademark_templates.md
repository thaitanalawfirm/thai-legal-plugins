# trademark_templates.md — แม่แบบเอกสารงานเครื่องหมายการค้า

ใช้แม่แบบเหล่านี้เป็นโครง ปรับตามงานและข้อเท็จจริง

> ทำเครื่องหมาย [....] ทุกจุดที่ต้องเติม · ยืนยันจำพวก/กำหนดเวลา/ค่าธรรมเนียมกับฉบับปัจจุบัน
> · ทุกฉบับเป็นร่างให้ผู้รับผิดชอบตรวจรับรองก่อนยื่น/ส่ง

---

## 1. แม่แบบบันทึกประเมินความเป็นไปได้ในการจดทะเบียน

```
บันทึกประเมินเครื่องหมายการค้า
เครื่องหมาย: [คำ/รูป/ผสม]    สินค้า/บริการ: [....]    วันที่: [....]

1. ลักษณะบ่งเฉพาะ
   [ประเมินว่าบ่งเฉพาะ/บรรยายสินค้า/คำสามัญ — ความเสี่ยง]
2. ลักษณะต้องห้าม
   [ตรวจว่ามีเหตุต้องห้ามหรือไม่]
3. ผลสืบค้นเครื่องหมายคล้าย
   [สรุปสิ่งที่พบและความเสี่ยงสับสน]
4. จำพวกและรายการสินค้า/บริการที่แนะนำ
   📝 [ยืนยันจำพวกกับฐานข้อมูลปัจจุบัน]
5. ความเห็นโดยสรุปและความเสี่ยง
   [ตรงไปตรงมา ไม่รับรองผล]
6. ข้อเสนอแนะ
   [เช่น ปรับเครื่องหมายให้แข็งขึ้น/เพิ่มองค์ประกอบ]
```

## 2. แม่แบบคำชี้แจง/โต้แย้งข้อโต้แย้งของนายทะเบียน (โครง)

```
คำชี้แจงประกอบคำขอเลขที่ [....]
เครื่องหมาย: [....]

ตามที่นายทะเบียนมีคำสั่ง/ข้อโต้แย้งว่า [สรุปข้อโต้แย้ง] นั้น
ผู้ขอขอเรียนชี้แจงดังนี้
   1. [เหตุผลข้อ 1 — อ้างหลักเกณฑ์จากตัวบทระดับ A และข้อเท็จจริง เช่น พิสูจน์ลักษณะบ่งเฉพาะ
      จากการใช้ / ชี้ความต่างจากเครื่องหมายที่ยกมา]
   2. [เหตุผลข้อ 2]

จึงขอให้นายทะเบียนพิจารณารับจดทะเบียนเครื่องหมายของผู้ขอ

* ยื่นภายในกำหนดเวลา [📝 ตรวจกำหนด]
```

## 3. แม่แบบหนังสือเตือนให้ยุติการละเมิด (Cease and Desist) — โครง

```
                                            วันที่ [....]
เรื่อง  ขอให้ยุติการใช้เครื่องหมายการค้าที่ละเมิดสิทธิ
เรียน  [ผู้ถูกกล่าวหาว่าละเมิด]

ด้วยบริษัท [....] เป็นเจ้าของเครื่องหมายการค้า [....] ทะเบียนเลขที่ [....]
ปรากฏว่าท่านได้ใช้เครื่องหมาย [....] ซึ่งเหมือน/คล้ายกับเครื่องหมายของบริษัทจนอาจทำให้
สาธารณชนสับสน อันเป็นการละเมิดสิทธิของบริษัท

บริษัทจึงขอให้ท่าน [ยุติการใช้ / เรียกคืน / ...] ภายใน [....] วัน นับแต่ได้รับหนังสือนี้
หากท่านเพิกเฉย บริษัทจำเป็นต้องดำเนินการตามกฎหมายต่อไป

                                ขอแสดงความนับถือ
                                [ผู้มีอำนาจ/ทนายความ]

* ตรวจข้อเท็จจริงเรื่องสิทธิและความคล้ายให้ชัดก่อนส่ง และให้ทนายผู้รับผิดชอบรับรอง
```

---

## ข้อควรจำ
- ประเมินตรงไปตรงมา ไม่รับรองว่าจดได้/ชนะแน่นอน
- ยืนยันจำพวก กำหนดเวลา และค่าธรรมเนียมกับฉบับปัจจุบัน (📝)
- อ้างหลักเกณฑ์จากตัวบทระดับ A ไม่ประดิษฐ์มาตรา
- ปิดท้ายด้วย "ข้อสังเกตจากทนาย" และระบุว่าเป็นร่างให้ผู้รับผิดชอบรับรอง
