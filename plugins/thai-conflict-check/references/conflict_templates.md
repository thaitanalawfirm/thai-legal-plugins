# conflict_templates.md — แม่แบบบันทึกผลการตรวจและหนังสือยินยอม

ใช้แม่แบบเหล่านี้บันทึกผลการตรวจ conflict และจัดทำเอกสารประกอบ

> ทำเครื่องหมาย [....] ทุกจุดที่ต้องเติม

---

## 1. แม่แบบบันทึกผลการตรวจ conflict

```
บันทึกผลการตรวจผลประโยชน์ขัดกัน (Conflict Check)

เรื่อง: [ชื่อเรื่อง/เลขเรื่อง]      วันที่ตรวจ: [....]      ผู้ตรวจ: [....]

1. รายชื่อที่นำมาตรวจ
   - ลูกความใหม่: [....]
   - คู่กรณี: [....]
   - ผู้เกี่ยวข้อง/นิติบุคคลเชื่อมโยง: [....]

2. ฐานข้อมูลที่เทียบ
   [ลูกความปัจจุบัน / ลูกความเดิม / คู่กรณีในเรื่องเดิม / ผู้เคยปรึกษา / ส่วนได้เสีย]

3. ผลการค้นเทียบ
   [ไม่พบรายการตรงกัน — หรือ — พบ: ระบุชื่อ/เรื่องที่เกี่ยวข้อง]

4. การวิเคราะห์ (หากพบ)
   - ประเภท conflict: [ปัจจุบัน/เดิม/ข้อมูลความลับ/ส่วนตัว/ลูกความร่วม]
   - ความเกี่ยวพันของเรื่อง: [....]
   - ประเด็นข้อมูลความลับ: [....]
   - ระดับความร้ายแรง: 🔴/🟡/🟢

5. ผลการประเมิน
   [ ] ไม่พบ conflict — รับงานต่อได้
   [ ] มี conflict รับไม่ได้ — ปฏิเสธงาน
   [ ] มี conflict จัดการได้ — รับได้ภายใต้เงื่อนไข: [ระบุ]

6. เงื่อนไขจัดการ (ถ้ามี)
   [หนังสือยินยอม / information barrier / อื่น ๆ]

7. การวินิจฉัยของทนายผู้รับผิดชอบ
   ลงชื่อ: [....]   วันที่: [....]

หมายเหตุ: บันทึกนี้เป็นผลการตรวจเบื้องต้นตามข้อมูลและฐานข้อมูลที่มี การวินิจฉัยขั้นสุดท้าย
อ้างอิงข้อบังคับมรรยาททนายความฉบับปัจจุบัน
```

## 2. แม่แบบหนังสือยินยอมหลังเปิดเผยข้อมูล (Informed Consent) — โครงร่าง

```
หนังสือให้ความยินยอม

เรียน [ลูกความ]

ตามที่สำนักงานได้พิจารณารับงาน [ระบุเรื่อง] สำนักงานขอเปิดเผยข้อเท็จจริงเกี่ยวกับสถานการณ์
ที่อาจถือเป็นผลประโยชน์ขัดกัน ดังนี้
   [อธิบายลักษณะ conflict และความเสี่ยงที่อาจมีต่อลูกความอย่างครบถ้วน]

สำนักงานได้อธิบายความเสี่ยงและทางเลือกข้างต้นให้ท่านทราบแล้ว หากท่านประสงค์ให้สำนักงานรับ
ดำเนินการต่อ โปรดลงนามให้ความยินยอมด้านล่าง

   ลงชื่อ ........................... ลูกความ      วันที่ ..............
```

> โครงนี้เป็นเพียงร่างตั้งต้น เนื้อหาการเปิดเผยต้องครบถ้วนตามลักษณะ conflict จริง และต้องให้
> ทนายผู้รับผิดชอบตรวจรับรองก่อนใช้ และพิจารณาว่ากรณีนั้นยินยอมได้ตามมรรยาทฯ หรือไม่

---

## ข้อควรจำ
- บันทึกผลการตรวจ **ทุกครั้ง** ไม่ว่าพบหรือไม่พบ conflict — เป็นหลักฐานว่าได้ตรวจ
- ไม่นำข้อมูลความลับของลูกความรายอื่นมาเปิดในบันทึก/หนังสือยินยอมเกินจำเป็น
- ปิดท้ายงานด้วย "ข้อสังเกตจากทนาย" ตามมาตรฐานของสกิลนี้ และย้ำว่าการวินิจฉัยขั้นสุดท้าย
  เป็นของทนายผู้รับผิดชอบ
