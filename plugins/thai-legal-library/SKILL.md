# thai-legal-library — คลังกฎหมายไทย

## วัตถุประสงค์

เป็น **คลังตัวบทกฎหมายไทย** กลางที่ปลั๊กอินงานทนายความตัวอื่น ๆ (เช่น `thai-litigation-pleadings`, `thai-legal-opinion`, `thai-compliance-audit`) เรียกใช้เพื่ออ้างมาตรา/บทบัญญัติ/หลักกฎหมายอย่างถูกต้อง โดยไม่ต้อง bundle ตัวบทกฎหมายเข้าทุกปลั๊กอิน

## เมื่อไรให้ใช้สกิลนี้

- เมื่อปลั๊กอินอื่นต้องอ้างมาตราในประมวลหรือ พ.ร.บ. ของไทย
- เมื่อต้องค้นหาตัวบทใดอยู่หมวดใด → เปิด `references/big_data_md/00_INDEX.md`
- เมื่อจะตรวจคุณภาพของไฟล์ในคลัง → เปิด `references/big_data_md/_QUALITY_REPORT.md`
- เมื่อต้องการรายการเลขฎีกาบรรทัดฐานที่ต้องตรวจสอบก่อนใช้ → เปิด section 3 ของ `_QUALITY_REPORT.md`
- เมื่อต้องการรายการเลขมาตราที่อ้างในไฟล์ B/C → เปิด section 4.1 ของ `_QUALITY_REPORT.md`

> **หมายเหตุ:** สกิลนี้คู่กับ `thai-legal-forms` ที่บรรจุแบบพิมพ์ศาล 192 ไฟล์ใน 15 กลุ่ม — ถ้าต้องใช้แบบฟอร์ม ลงปลั๊กอินนั้นด้วย

## โครงสร้างคลัง

```
references/big_data_md/
├── 00_INDEX.md            ← สารบัญกลาง — เปิดอันนี้ก่อนเสมอ
├── _QUALITY_REPORT.md     ← รายงานคุณภาพ + รายการเลขฎีกา/มาตรา
├── 01_codes/              ← ประมวลกฎหมาย (5 ไฟล์)
├── 02_procedure/          ← กฎหมายวิธีพิจารณา + พ.ร.บ.จัดตั้งศาล (11 ไฟล์)
├── 03_acts/               ← พ.ร.บ./พ.ร.ก. สารบัญญัติเฉพาะ (19 ไฟล์)
├── 04_regulations/        ← กฎหมายลำดับรอง/ประกาศ (5 ไฟล์)
├── 05_dika/               ← คำพิพากษาฎีกาบรรทัดฐาน (2 ไฟล์)
└── 07_practical/          ← เอกสารเสริมเชิงปฏิบัติ (3 ไฟล์)
```

แบบพิมพ์ศาล (06_forms) อยู่ในปลั๊กอินคู่ `thai-legal-forms` แยกต่างหาก

## หลักการสำคัญ

1. **ใช้ 00_INDEX.md เป็นจุดเริ่มต้นเสมอ** — ระบุไฟล์ที่ต้องเปิด ระดับคุณภาพ (A/B/C) และปลั๊กอินที่จะใช้
2. **เคารพนโยบาย 3 ชั้น** — ระดับ A อ้างได้ตรง · ระดับ B/C ใช้เป็นไกด์ค้น · ฎีกาต้องตรวจกับ "สืบค้นฎีกา 2015" ก่อนอ้าง
3. **ห้ามแก้ไขเนื้อหาตัวบท** — เป็น read-only reference; การอัปเดตทำผ่านการแพ็กปลั๊กอินรุ่นใหม่
4. **ตรวจฉบับแก้ไขล่าสุดก่อนใช้** — ตัวบทในคลังอาจตามฉบับแก้ไขไม่ทันถ้ามีการแก้ไขใหม่หลังวันที่แพ็ก

## ข้อห้ามเด็ดขาด

❌ ห้ามแก้ไขเนื้อหาในไฟล์ของคลัง — ใช้เป็น read-only reference เท่านั้น
❌ ห้ามประดิษฐ์เลขมาตรา/ฎีกา หรือข้อกฎหมายที่ไม่มีอยู่จริง — ถ้าคลังไม่มี ให้ระบุชัดเจนว่า "ไม่พบในคลัง" และให้ตรวจกับฉบับปัจจุบัน
❌ ห้ามอ้างเลขฎีกาจาก 05_dika หรือ 07_practical ลงในคำคู่ความโดยไม่ตรวจกับระบบสืบค้นฎีกาของศาลฎีกาก่อน (โดยเฉพาะปี 2566+)
❌ ห้ามตีความว่าคลังเป็น "ทางการ" — ตัวบทจริงต้องตรวจกับ http://www.krisdika.go.th หรือราชกิจจานุเบกษา

- `thai-corporate-secretarial`, `thai-matter-management`
- `thai-patent`, `thai-trademark`
