# ฐานข้อมูลรายชื่อศาลและเขตอำนาจตามท้องที่ของไทย

> เอกสารนี้จัดทำเป็น **ฐานข้อมูลตั้งต้น** สำหรับสำนักงานกฎหมาย ใช้ช่วยคัดกรองว่า “คดีควรยื่นศาลใด” ก่อนตรวจสอบรายละเอียดสุดท้ายจากเว็บไซต์ศาล/ประกาศเขตอำนาจ/กฎหมายเฉพาะอีกครั้ง

## วิธีใช้แบบเร็ว

1. ระบุประเภทคดี: แพ่ง / อาญา / แรงงาน / เยาวชนและครอบครัว / ล้มละลาย / ภาษี / ทรัพย์สินทางปัญญา / ปกครอง / ทหาร / รัฐธรรมนูญ
2. ระบุจุดเกาะเกี่ยวของคดี:
   - ภูมิลำเนาจำเลย
   - สถานที่เกิดเหตุ
   - สถานที่ทำสัญญา/ชำระหนี้
   - ที่ตั้งทรัพย์พิพาท
   - สถานที่ทำงาน/สถานประกอบกิจการ
   - ที่ตั้งหน่วยงานรัฐ
3. ตรวจว่ามีศาลชำนัญพิเศษหรือศาลเฉพาะบังคับหรือไม่
4. ตรวจเขตอำนาจท้องที่รายจังหวัด/รายอำเภอ
5. ตรวจทุนทรัพย์และอัตราโทษ เพื่อแยกศาลจังหวัด/ศาลแขวง/ศาลแพ่ง/ศาลอาญา/ศาลอาญากรุงเทพใต้ ฯลฯ
6. ตรวจข้อสัญญาเลือกศาล/อนุญาโตตุลาการ หากมี

# 1. โครงสร้างศาลไทยแบบฐานข้อมูล

## 1.1 ศาลยุติธรรม

| ชั้นศาล | ประเภทศาล | ตัวอย่าง | หมายเหตุ |
|---|---|---|---|
| ศาลชั้นต้น | ศาลทั่วไป | ศาลจังหวัด, ศาลแขวง, ศาลแพ่ง, ศาลอาญา | พิจารณาคดีแพ่ง/อาญาทั่วไป |
| ศาลชั้นต้น | ศาลชำนัญพิเศษ | ศาลแรงงาน, ศาลเยาวชนและครอบครัว, ศาลภาษีอากร, ศาลล้มละลาย, ศาลทรัพย์สินทางปัญญาและการค้าระหว่างประเทศ | ต้องดู พ.ร.บ. จัดตั้งศาลนั้น ๆ |
| ศาลอุทธรณ์ | ศาลอุทธรณ์/ศาลอุทธรณ์ภาค | ศาลอุทธรณ์ภาค 1-9 | รับอุทธรณ์จากศาลชั้นต้นตามเขต |
| ศาลอุทธรณ์คดีชำนัญพิเศษ | เฉพาะคดีชำนัญพิเศษ | แรงงาน/ภาษี/ล้มละลาย/IP/เยาวชนฯ ตามที่กฎหมายกำหนด | ต้องดูทางอุทธรณ์เฉพาะคดี |
| ศาลฎีกา | ศาลสูงสุดของศาลยุติธรรม | ศาลฎีกา | ทั่วราชอาณาจักร |

## 1.2 ศาลปกครอง

| ชั้นศาล | ประเภท | หมายเหตุ |
|---|---|---|
| ศาลปกครองชั้นต้น | ศาลปกครองกลางและศาลปกครองภูมิภาค | คดีพิพาททางปกครอง |
| ศาลปกครองสูงสุด | ศาลสูงสุดของระบบศาลปกครอง | พิจารณาอุทธรณ์/คดีที่กฎหมายกำหนด |

## 1.3 ศาลรัฐธรรมนูญ

ไม่มีการแบ่งเขตอำนาจตามจังหวัด ใช้เฉพาะกรณีตามรัฐธรรมนูญและกฎหมายประกอบรัฐธรรมนูญ

## 1.4 ศาลทหาร

พิจารณาตามสถานะบุคคล ประเภทความผิด และกฎหมายว่าด้วยธรรมนูญศาลทหาร

# 2. หลักเลือกศาลตามประเภทคดี

## 2.1 คดีแพ่งทั่วไป

| ประเด็นตรวจ | หลักปฏิบัติ |
|---|---|
| จำเลยมีภูมิลำเนาอยู่ที่ใด | ฟ้องศาลที่จำเลยมีภูมิลำเนา |
| เหตุแห่งคดีเกิดที่ใด | อาจฟ้องศาลที่เหตุแห่งคดีเกิด |
| คดีเกี่ยวกับอสังหาริมทรัพย์ | มักตรวจศาลที่ทรัพย์ตั้งอยู่ |
| สัญญาระบุสถานที่ชำระหนี้ | ตรวจว่าสถานที่ชำระหนี้เป็นเหตุให้เลือกศาลได้หรือไม่ |
| มีข้อสัญญาเลือกศาล | ตรวจความสมบูรณ์และผลบังคับของข้อสัญญา |
| ทุนทรัพย์ต่ำ/คดีเล็ก | ตรวจว่าอยู่ในอำนาจศาลแขวงหรือไม่ |

## 2.2 คดีอาญาทั่วไป

| ประเด็นตรวจ | หลักปฏิบัติ |
|---|---|
| ความผิดเกิดที่ใด | ฟ้อง/ร้องทุกข์ในท้องที่เกิดเหตุ |
| อ้าง/เชื่อว่าความผิดเกิดในเขตใด | ตรวจท้องที่สอบสวนและศาลที่มีอำนาจ |
| จำเลยถูกจับ/มีที่อยู่ | อาจมีผลต่อท้องที่สอบสวนหรือศาลในบางกรณี |
| อัตราโทษ | แยกศาลแขวง/ศาลจังหวัด/ศาลอาญา |
| เป็นความผิดเฉพาะ | เช่น เยาวชน, ค้ามนุษย์, ทุจริต, ยาเสพติด ฯลฯ ต้องตรวจศาลเฉพาะหรือแผนกเฉพาะ |

## 2.3 คดีแรงงาน

| ประเด็นตรวจ | หลักปฏิบัติ |
|---|---|
| สถานที่ทำงาน/สถานประกอบกิจการ | ใช้ตรวจเขตศาลแรงงาน |
| นายจ้าง/ลูกจ้างอยู่ที่ใด | ใช้ประกอบการพิจารณาท้องที่ |
| ข้อพิพาทเกิดจากสัญญาจ้าง/สิทธิแรงงาน | เข้าศาลแรงงาน ไม่ใช่ศาลแพ่งทั่วไป |
| เป็นคดีประกันสังคม/เงินทดแทน | ตรวจว่ากฎหมายเฉพาะกำหนดศาลหรือกระบวนการอุทธรณ์ก่อนฟ้องหรือไม่ |

## 2.4 คดีเยาวชนและครอบครัว

| ประเภท | ศาลที่ควรตรวจ |
|---|---|
| หย่า, อำนาจปกครอง, ค่าอุปการะเลี้ยงดู, บุตร | ศาลเยาวชนและครอบครัว |
| เด็กหรือเยาวชนกระทำผิดอาญา | ศาลเยาวชนและครอบครัว |
| รับรองบุตร/เพิกถอนอำนาจปกครอง/คุ้มครองสวัสดิภาพ | ศาลเยาวชนและครอบครัว |

## 2.5 คดีปกครอง

| ประเภทข้อพิพาท | ศาลที่ควรตรวจ |
|---|---|
| คำสั่งทางปกครองไม่ชอบ | ศาลปกครอง |
| หน่วยงานรัฐ/เจ้าหน้าที่รัฐละเลยล่าช้า | ศาลปกครอง |
| สัญญาทางปกครอง | ศาลปกครอง |
| ละเมิดจากการใช้อำนาจทางปกครอง | ศาลปกครอง |

## 2.6 คดีชำนัญพิเศษอื่น

| ประเภทคดี | ศาล |
|---|---|
| ล้มละลาย/ฟื้นฟูกิจการ | ศาลล้มละลาย |
| ภาษีอากร | ศาลภาษีอากร |
| ทรัพย์สินทางปัญญาและการค้าระหว่างประเทศ | ศาลทรัพย์สินทางปัญญาและการค้าระหว่างประเทศ |
| แรงงาน | ศาลแรงงาน |
| เยาวชนและครอบครัว | ศาลเยาวชนและครอบครัว |
| คดีทุจริตและประพฤติมิชอบ | ศาลอาญาคดีทุจริตและประพฤติมิชอบ |

# 6. ฐานข้อมูลศาลปกครองชั้นต้น

> ใช้เมื่อตรวจพบว่าเป็นคดีพิพาททางปกครอง เช่น คำสั่งทางปกครอง สัญญาทางปกครอง ละเลยล่าช้า ละเมิดจากการใช้อำนาจรัฐ

| กลุ่ม | ศาลปกครองที่ควรตรวจ | หมายเหตุ |
|---|---|---|
| ส่วนกลาง | ศาลปกครองกลาง | กรุงเทพฯ และพื้นที่ตามที่กฎหมาย/ประกาศกำหนด |
| ภูมิภาค | ศาลปกครองภูมิภาค | แบ่งเขตตามพื้นที่จังหวัด ต้องตรวจเขตล่าสุด |
| ศาลสูง | ศาลปกครองสูงสุด | อุทธรณ์/คดีที่กฎหมายกำหนด |

รายการตรวจในคดีปกครอง:
- หน่วยงานรัฐ/เจ้าหน้าที่รัฐเป็นคู่กรณีหรือไม่
- เป็นการใช้อำนาจทางปกครองหรือไม่
- มีคำสั่งทางปกครองหรือไม่
- ต้องอุทธรณ์ภายในฝ่ายปกครองก่อนฟ้องหรือไม่
- อายุความ/กำหนดเวลาฟ้องคดีปกครองครบหรือไม่

# 10. หมายเหตุทางปฏิบัติสำหรับสำนักงานกฎหมาย

1. อย่าเลือกศาลจาก “จังหวัด” อย่างเดียว ต้องดูระดับ “อำเภอ/เขต/แขวง” ด้วย
2. คดีในกรุงเทพฯ ต้องตรวจละเอียดเป็นพิเศษ เพราะมีศาลแพ่ง/อาญา/แขวงหลายแห่ง
3. คดีแรงงานให้เริ่มจาก “สถานที่ทำงาน/สถานประกอบกิจการ”
4. คดีครอบครัวและเยาวชนต้องแยกจากแพ่ง/อาญาทั่วไป
5. คดีปกครองต้องตรวจว่าต้องอุทธรณ์ในฝ่ายปกครองก่อนฟ้องหรือไม่
6. คดีภาษีต้องตรวจขั้นตอนอุทธรณ์ภาษีก่อน
7. คดีล้มละลายต้องตรวจทุนหนี้ สถานะลูกหนี้ และศาลที่กฎหมายกำหนด
8. คดี IP และการค้าระหว่างประเทศ อย่าเผลอยื่นศาลแพ่งทั่วไปหากเข้าศาลชำนัญพิเศษ
9. คดีอาญาเอกชนต้องตรวจทั้งเขตอำนาจศาลและอายุความร้องทุกข์/ฟ้อง
10. ก่อนยื่นฟ้องทุกครั้งควรบันทึกเหตุผลการเลือกศาลไว้ในสำนวนภายในสำนักงาน
