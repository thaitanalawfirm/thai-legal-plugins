# witness_prep.md — การเตรียมพยานบุคคลก่อนเบิกความ

อ่านไฟล์นี้เมื่อต้องเตรียมพยานบุคคลของฝ่ายผู้ใช้ให้พร้อมขึ้นเบิกความ

> ⚠️ การเตรียมพยานต้องอยู่ในกรอบจริยธรรมอย่างเคร่งครัด อ่านส่วนที่ 1 ก่อนเสมอ

---

## สารบัญ
1. เส้นแบ่งสำคัญ — เตรียมพยานได้ แต่ห้ามแต่งพยาน
2. สิ่งที่การเตรียมพยานควรครอบคลุม
3. การซ้อมเบิกความ
4. การเตรียมพยานรับมือการถามค้าน
5. ข้อควรระวังเฉพาะกลุ่มพยาน
6. แม่แบบบันทึกเตรียมพยาน

---

## 1. เส้นแบ่งสำคัญ — เตรียมพยานได้ แต่ห้ามแต่งพยาน

**การเตรียมพยานที่ชอบ** คือการช่วยให้พยานเบิกความ **ความจริงที่ตนรู้เห็น** ได้อย่างชัดเจน
ครบถ้วน และไม่ตื่นเต้นจนพลาด — ได้แก่ การอธิบายกระบวนการ การทบทวนเหตุการณ์ตามที่พยานจำได้จริง
การแนะนำเรื่องการพูดให้ชัด

**การเตรียมพยานที่ต้องห้ามเด็ดขาด** คือการทำให้พยานเบิกความ **ผิดจากความจริง** — ได้แก่:
- บอกพยานว่าให้ตอบอย่างไรทั้งที่ขัดกับสิ่งที่พยานรู้เห็นจริง
- เขียนบท/ท่องคำตอบให้พยาน
- ชักจูงให้พยาน"จำ" สิ่งที่ไม่ได้เกิดขึ้น
- ประสานคำเบิกความระหว่างพยานหลายปากให้ตรงกันทั้งที่ความจริงต่างกัน

การเบิกความเท็จเป็นความผิดอาญา และการชักจูงพยานให้เบิกความเท็จทำให้ทนายมีความผิดด้วย —
**หากผู้ใช้ขอให้ช่วยทำสิ่งในกลุ่มต้องห้าม ให้ปฏิเสธและอธิบายกรอบที่ถูกต้อง**

## 2. สิ่งที่การเตรียมพยานควรครอบคลุม

- **อธิบายกระบวนการ** — พยานจะถูกถามโดยใคร ตามลำดับใด (ซักถาม → ถามค้าน → ถามติง) บรรยากาศ
  ในห้องพิจารณา การสาบานตน
- **ทบทวนประเด็นที่พยานปากนี้จะเบิกความ** — ให้พยานทบทวนเหตุการณ์ตามที่ตนจำได้ และทนายช่วย
  ระบุว่าข้อเท็จจริงใดสำคัญต่อคดี
- **ทบทวนเอกสารที่เกี่ยวข้อง** — ให้พยานดูเอกสารที่ตนจะต้องอธิบาย
- **แนะนำวิธีการพูด** — ตอบเฉพาะที่ถูกถาม พูดชัด ช้า ๆ ตอบเท่าที่รู้ ถ้าไม่รู้/จำไม่ได้
  ให้บอกตามจริงว่าไม่รู้/จำไม่ได้ ไม่เดา

## 3. การซ้อมเบิกความ

- ซ้อมโดยใช้ **คำถามจริงที่เตรียมไว้** (ดู `examination_in_chief.md`) ให้พยานคุ้นเคยกับลำดับ
- เน้นย้ำว่าการซ้อมคือการ **ฝึกเล่าความจริงให้ชัด** ไม่ใช่ท่องบท — คำตอบในวันจริงต้องเป็น
  ถ้อยคำของพยานเอง
- สังเกตจุดที่พยานเล่าสับสนหรือตกหล่น แล้วช่วยให้พยานเรียบเรียงความจำของตนให้เป็นระเบียบ

## 4. การเตรียมพยานรับมือการถามค้าน

- อธิบายให้พยานเข้าใจว่าการถามค้านเป็นเรื่องปกติ ทนายอีกฝ่ายจะถามด้วยคำถามนำและพยายามคุม
  ทิศทาง
- แนวทางที่แนะนำพยานได้: ฟังคำถามให้จบก่อนตอบ ตอบเฉพาะที่ถูกถาม ไม่โต้เถียง ไม่เดา หากไม่
  เข้าใจคำถามให้ขอให้ถามใหม่ หากจำไม่ได้ให้บอกว่าจำไม่ได้
- ทบทวนกับพยานว่าจุดใดของคำเบิกความที่อีกฝ่ายน่าจะถามค้าน เพื่อให้พยานไม่ตกใจ — แต่ยังคง
  ตอบตามความจริง

## 5. ข้อควรระวังเฉพาะกลุ่มพยาน

- **พยานที่เป็นเด็กหรือเยาวชน** — มีวิธีพิจารณาคุ้มครองพิเศษ (การสอบผ่านนักจิตวิทยา/
  นักสังคมสงเคราะห์ การใช้ห้องพิเศษ) ต้องคำนึงถึงความปลอดภัยและสภาพจิตใจของเด็กเป็นสำคัญ
- **พยานผู้เสียหายในคดีละเอียดอ่อน** — ระวังเรื่องการกระทำซ้ำทางจิตใจ
- **พยานผู้เชี่ยวชาญ** — เตรียมให้พร้อมอธิบายวิธีการและฐานข้อมูล และรับมือการถามค้านเรื่อง
  ความเป็นกลาง

## 6. แม่แบบบันทึกเตรียมพยาน

```
บันทึกเตรียมพยาน — พยานปากที่ ... : [ชื่อพยาน]
ประเด็นที่พยานปากนี้นำสืบ: [ระบุ]

ก. ข้อเท็จจริงที่พยานรู้เห็นจริง (ตามที่พยานเล่า):
   [สรุปตามคำบอกเล่าของพยาน — ไม่เติมแต่ง]

ข. ข้อเท็จจริงสำคัญที่ต้องให้ครบในการเบิกความ:
   [ไล่รายการ อ้างอิงประเด็น]

ค. เอกสารที่พยานจะต้องอธิบาย:
   [รายการเอกสาร]

ง. จุดที่อีกฝ่ายน่าจะถามค้าน และแนวที่พยานควรเข้าใจ (โดยตอบตามจริง):
   [ระบุ]

จ. ข้อที่พยานยังจำไม่ได้/ไม่แน่ใจ (ให้ตอบตามจริงว่าจำไม่ได้):
   [ระบุ]
```

## Checklist การเตรียมพยาน
- [ ] การเตรียมทั้งหมดอยู่บนพื้นฐานความจริงที่พยานรู้เห็น ไม่มีการแต่งเรื่อง
- [ ] พยานเข้าใจกระบวนการและลำดับการถาม
- [ ] พยานเข้าใจว่าให้ตอบตามจริง ตอบเท่าที่รู้ ไม่เดา
- [ ] ซ้อมด้วยคำถามจริง แต่คำตอบเป็นถ้อยคำของพยานเอง
- [ ] เตรียมพยานให้รับมือการถามค้านได้โดยยังตอบตามความจริง
- [ ] กรณีพยานเด็ก/ผู้เสียหายในคดีละเอียดอ่อน — คำนึงถึงการคุ้มครองเป็นพิเศษ
