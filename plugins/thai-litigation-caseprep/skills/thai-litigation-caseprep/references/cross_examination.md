# cross_examination.md — การถามค้านพยานฝ่ายตรงข้าม

อ่านไฟล์นี้เมื่อต้องเตรียมคำถามถามค้านพยานที่คู่ความอีกฝ่ายนำเข้าสืบ

> ⚠️ เลขมาตราเป็นแนวอ้างอิงตาม ป.วิ.พ. และ ป.วิ.อาญา ให้ยืนยันกับตัวบทฉบับปัจจุบัน

---

## สารบัญ
1. เป้าหมายของการถามค้าน
2. หลักการตัดสินใจว่าจะถามค้านหรือไม่
3. หลักการตั้งคำถามถามค้าน
4. แนวทางถามค้านที่ใช้บ่อย
5. กรอบจริยธรรมและข้อห้าม
6. โครงเตรียมคำถามถามค้าน

---

## 1. เป้าหมายของการถามค้าน

การถามค้านมีเป้าหมายอย่างใดอย่างหนึ่งหรือหลายอย่าง:
- **ลดน้ำหนักคำเบิกความ** ของพยานปากนั้น (แสดงว่าพยานไม่อยู่ในฐานะรู้เห็นจริง จำคลาดเคลื่อน
  มีอคติ หรือมีส่วนได้เสีย)
- **ดึงข้อเท็จจริงที่เป็นประโยชน์ต่อฝ่ายตน** ออกจากปากพยานอีกฝ่าย
- **แสดงความขัดแย้ง** ระหว่างคำเบิกความของพยานกับเอกสาร กับพยานปากอื่น หรือกับคำเบิกความ
  ของพยานเองในตอนต้น
- **ปูทางสำหรับคำแถลงการณ์ปิดคดี** — ให้ได้คำตอบที่จะนำไปอ้างในตอนสรุป

## 2. หลักการตัดสินใจว่าจะถามค้านหรือไม่

- ถามค้านเมื่อมี **เป้าหมายชัด** เท่านั้น — ถ้าพยานไม่ได้ทำให้ฝ่ายตนเสียหาย หรือถามไปก็มีแต่
  เปิดโอกาสให้พยานย้ำเรื่องที่เสียเปรียบ การ **ไม่ถามค้าน** ก็เป็นทางเลือกที่ดี
- ระบุก่อนถามทุกครั้งว่า "คำถามชุดนี้ต้องการได้อะไร" — ถ้าตอบไม่ได้ ไม่ควรถาม
- เลือกถามเฉพาะจุดที่มีโอกาสได้ผล อย่าถามค้านทุกเรื่องจนเสียจุดโฟกัส

## 3. หลักการตั้งคำถามถามค้าน

- **ใช้คำถามนำได้และควรใช้** — คำถามถามค้านควรเป็นประโยคยืนยันสั้น ๆ ที่พยานตอบได้เพียง
  "ใช่" หรือ"ไม่ใช่" เพื่อให้ทนายเป็นผู้คุมทิศทาง ไม่ใช่ปล่อยให้พยานอธิบาย
- **ถามทีละข้อเท็จจริงเล็ก ๆ** — ไม่ถามคำถามใหญ่ที่เปิดช่องให้พยานอธิบายยาว
- **อย่าถามคำถามที่ไม่รู้คำตอบ** ในประเด็นสำคัญ — ถามเฉพาะเมื่อคาดผลได้ หรือเมื่อคำตอบทาง
  ใดก็เป็นประโยชน์
- **คุมพยาน** — หากพยานพยายามอธิบายนอกประเด็น ดึงกลับด้วยคำถามที่เฉพาะเจาะจง
- **เก็บหมัดเด็ดไว้ท้าย** — ค่อย ๆ ปูข้อเท็จจริงทีละชิ้นก่อนถึงคำถามชี้ขาด อย่าเปิดไพ่เร็ว
- **รู้ว่าเมื่อใดควรหยุด** — เมื่อได้คำตอบที่ต้องการแล้ว หยุด อย่าถามต่อจนพยานมีโอกาสกลบ

## 4. แนวทางถามค้านที่ใช้บ่อย

- **โจมตีฐานการรู้เห็น** — พยานอยู่ตรงนั้นจริงหรือไม่ ระยะห่าง แสง เวลา ทัศนวิสัย
- **โจมตีความจำ** — เหตุการณ์ผ่านมานานเท่าใด พยานจำรายละเอียดอื่นได้หรือไม่
- **แสดงอคติ/ส่วนได้เสีย** — ความสัมพันธ์ของพยานกับคู่ความ ผลประโยชน์ที่พยานมี
- **ชี้ความขัดแย้งกับเอกสาร** — ให้พยานยืนยันคำเบิกความ แล้วเทียบกับเอกสารที่ขัดกัน
- **ชี้ความขัดแย้งภายใน** — เทียบคำเบิกความช่วงต้นกับช่วงหลัง หรือกับคำให้การชั้นสอบสวน
- **ดึงข้อเท็จจริงที่เป็นคุณ** — ถามเฉพาะข้อที่พยานต้องยอมรับและเป็นประโยชน์ต่อฝ่ายตน

## 5. กรอบจริยธรรมและข้อห้าม

- ถามค้านได้หนักแน่นและเฉียบคม แต่ต้องอยู่ในกรอบความสุจริตและความเคารพต่อศาล
- **ห้าม** ตั้งคำถามที่อ้างข้อเท็จจริงที่รู้อยู่ว่าไม่จริง หรือสร้างเรื่องเพื่อหลอกพยาน
- **ห้าม** ข่มขู่ คุกคาม หรือดูหมิ่นพยานโดยมิชอบ
- **ห้าม** ติดต่อ จูงใจ หรือข่มขู่พยานฝ่ายตรงข้ามนอกศาลโดยมิชอบ
- คำถามที่ไม่เกี่ยวกับประเด็น หรือเป็นการประวิง ศาลอาจห้ามได้

## 6. โครงเตรียมคำถามถามค้าน

```
แผนถามค้าน — พยานปากที่ ... : [ชื่อพยานของอีกฝ่าย]
พยานปากนี้เบิกความสนับสนุนประเด็นใดของอีกฝ่าย: [ระบุ]
จะถามค้านหรือไม่: [ถาม / ไม่ถาม] — เหตุผล: [ระบุ]

ชุดที่ 1 — เป้าหมาย: [เช่น แสดงว่าพยานไม่อยู่ในฐานะรู้เห็นจริง]
  - [คำถามนำสั้น ๆ ที่ตอบได้ใช่/ไม่ใช่ เรียงปูไปสู่คำถามชี้ขาด]

ชุดที่ 2 — เป้าหมาย: [เช่น ชี้ความขัดแย้งกับเอกสาร จ.5]
  - [คำถามให้พยานยืนยันคำเบิกความ แล้วเผชิญกับเอกสารที่ขัดกัน]

ชุดที่ 3 — เป้าหมาย: [เช่น ดึงข้อเท็จจริงที่เป็นคุณต่อฝ่ายเรา]
  - [คำถามเฉพาะข้อที่พยานต้องยอมรับ]

ข้อเท็จจริงที่ได้จากการถามค้านนี้ จะนำไปใช้ในคำแถลงการณ์ปิดคดีอย่างไร:
  - [ระบุ]
```

## Checklist การถามค้าน
- [ ] ทุกชุดคำถามมีเป้าหมายชัด — ถ้าไม่มีเป้าหมาย ไม่ถาม
- [ ] ใช้คำถามนำสั้น ๆ ที่คุมทิศทางได้ ไม่เปิดให้พยานอธิบายยาว
- [ ] ไม่ถามคำถามสำคัญที่ไม่รู้คำตอบ
- [ ] เก็บคำถามชี้ขาดไว้หลังปูข้อเท็จจริงครบ
- [ ] หยุดเมื่อได้คำตอบที่ต้องการแล้ว
- [ ] อยู่ในกรอบจริยธรรม ไม่อ้างข้อเท็จจริงเท็จและไม่คุกคามพยาน
