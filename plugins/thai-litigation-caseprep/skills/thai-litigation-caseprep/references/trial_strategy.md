# trial_strategy.md — แผนสู้คดี การเตรียมวันสืบพยาน และคำแถลงการณ์ปิดคดี

อ่านไฟล์นี้เมื่อต้องวางแผนภาพรวมของคดี เตรียมตัวสำหรับวันนัด หรือร่างคำแถลงการณ์ปิดคดี

> ⚠️ เลขมาตราเป็นแนวอ้างอิงตาม ป.วิ.พ. และ ป.วิ.อาญา ให้ยืนยันกับตัวบทฉบับปัจจุบัน

---

## สารบัญ
1. องค์ประกอบของแผนสู้คดี
2. การเตรียมตัวสำหรับวันชี้สองสถาน
3. การเตรียมตัวสำหรับวันนัดสืบพยาน
4. การไกล่เกลี่ยและทางเลือกการยุติคดี
5. คำแถลงการณ์ปิดคดี
6. แม่แบบแผนสู้คดี

---

## 1. องค์ประกอบของแผนสู้คดี

แผนสู้คดีที่สมบูรณ์ควรรวม:
- **ทฤษฎีคดี** — เรื่องราวในมุมฝ่ายตน (ดู `issue_analysis.md`)
- **ผังประเด็นและภาระการพิสูจน์** — ประเด็นใดต้องนำสืบ ใครมีหน้าที่
- **แผนพยาน** — พยานต่อประเด็น ลำดับการสืบ (ดู `evidence_management.md`)
- **การประเมินจุดแข็ง-จุดอ่อน** — ของฝ่ายตนและของอีกฝ่าย อย่างตรงไปตรงมา
- **การคาดการณ์แนวทางของอีกฝ่าย** — อีกฝ่ายจะนำสืบอย่างไร จะถามค้านพยานเราจุดใด
- **แผนสำรอง** — หากพยานปากสำคัญไม่มา หรือประเด็นใดนำสืบไม่ได้ตามคาด
- **การประเมินผลลัพธ์ที่เป็นไปได้และทางเลือกยุติคดี** (ดูข้อ 4)

## 2. การเตรียมตัวสำหรับวันชี้สองสถาน

- เตรียม **ประเด็นข้อพิพาทที่ฝ่ายตนเห็นว่าถูกต้อง** ไปเสนอต่อศาล
- เตรียมโต้แย้งหากศาลกำหนดประเด็นหรือหน้าที่นำสืบไม่ตรงกับที่ควรเป็น เพราะการกำหนดประเด็น
  และภาระการพิสูจน์มีผลต่อรูปคดีทั้งหมด
- ตรวจว่ามีข้อที่ควรยื่นคำร้องก่อนวันชี้สองสถานหรือไม่ (เช่น ขอแก้ไขคำฟ้อง — ดูสกิล
  `thai-litigation-motions`)

## 3. การเตรียมตัวสำหรับวันนัดสืบพยาน

- ตรวจว่า **ยื่นบัญชีระบุพยานครบและทันกำหนด** แล้ว
- จัดลำดับพยานให้เล่าเรื่องตามทฤษฎีคดีได้ต่อเนื่อง และนัดหมายพยานให้มาตรงวัน
- เตรียม **เอกสารต้นฉบับ** และสำเนาสำหรับศาลและคู่ความ จัดเรียงตามหมายเลขพยานเอกสาร
- เตรียมชุดคำถามซักถามรายปาก และแผนถามค้านพยานอีกฝ่ายรายปาก
- เตรียมพยานบุคคลให้พร้อม (ดู `witness_prep.md`)
- หากพยานปากสำคัญไม่อาจมาได้ พิจารณายื่นคำร้องที่เหมาะสม (เช่น ขอเลื่อน — ดูสกิล
  `thai-litigation-motions`) โดยมีเหตุอันสมควร

## 4. การไกล่เกลี่ยและทางเลือกการยุติคดี

- คดีส่วนใหญ่มีช่องทาง **ไกล่เกลี่ย** ทั้งก่อนฟ้องและระหว่างพิจารณา
- ประเมินตามความเป็นจริงว่าการ **ประนีประนอมยอมความ** เป็นประโยชน์กว่าการสู้จนจบหรือไม่
  โดยชั่งน้ำหนักพยานหลักฐาน ค่าใช้จ่าย เวลา และความเสี่ยง
- หากตกลงกันได้ ผลของการประนีประนอมยอมความในศาลจะถูกบันทึกเป็นสัญญาประนีประนอมและศาล
  พิพากษาตามยอม — อธิบายผลผูกพันให้ผู้ใช้ทราบ
- การตัดสินใจยอมความเป็นสิทธิของตัวความ ทนายให้ข้อมูลและคำแนะนำ ไม่ตัดสินใจแทน

## 5. คำแถลงการณ์ปิดคดี

**วัตถุประสงค์:** สรุปให้ศาลเห็นว่า เมื่อพิจารณาพยานหลักฐานทั้งหมดแล้ว ประเด็นข้อพิพาทควร
วินิจฉัยไปในทางที่ฝ่ายตนชนะ
**โครงสร้างที่ดี:**
1. ทบทวนประเด็นข้อพิพาทและภาระการพิสูจน์
2. ไล่ทีละประเด็น — ประเด็นนี้พยานหลักฐานใดสนับสนุนข้ออ้างของฝ่ายตน อ้างคำเบิกความของพยาน
   ปากใด ตอนใด และเอกสารหมายใด
3. ชี้จุดอ่อนและข้อขัดแย้งในพยานหลักฐานของอีกฝ่าย (โดยอ้างสิ่งที่ได้จากการถามค้าน)
4. ปรับบทกฎหมายเข้ากับข้อเท็จจริงที่นำสืบได้
5. สรุปคำขอ — ขอให้ศาลพิพากษาไปในทางใด
**หลักสำคัญ:** อ้างเฉพาะ **พยานหลักฐานที่อยู่ในสำนวนจริง** — ห้ามอ้างพยานหลักฐานหรือคำ
เบิกความที่ไม่ได้นำสืบ และห้ามประดิษฐ์คำพิพากษาฎีกาประกอบ

## 6. แม่แบบแผนสู้คดี

```
แผนสู้คดี — คดี [ชื่อคดี] หมายเลขดำที่ ......./........
ฝ่ายที่วางแผน: [โจทก์/จำเลย]

1. ทฤษฎีคดี (หนึ่งประโยค):
   [.....]

2. ผังประเด็น × ภาระการพิสูจน์ × พยาน:
   [อ้างอิงผังจาก issue_analysis.md]

3. ลำดับการสืบพยานฝ่ายเรา:
   ปากที่ 1 [ชื่อ] — ประเด็น [...]
   ปากที่ 2 ...

4. แผนรับมือพยานอีกฝ่าย:
   [พยานปากใดถามค้าน ปากใดไม่ถาม — อ้างแผนจาก cross_examination.md]

5. จุดแข็งของคดีเรา:
   [.....]

6. จุดอ่อนของคดีเรา และวิธีบรรเทา:
   [.....]

7. ผลลัพธ์ที่เป็นไปได้ และการประเมินทางเลือกไกล่เกลี่ย:
   [.....]

8. แผนสำรอง:
   [.....]
```

## Checklist แผนสู้คดี
- [ ] ทฤษฎีคดีชัดและสรุปได้ในประโยคเดียว
- [ ] ทุกประเด็นที่ฝ่ายตนมีภาระพิสูจน์ มีพยานรองรับและมีลำดับการสืบ
- [ ] ประเมินจุดแข็ง-จุดอ่อนของทั้งสองฝ่ายอย่างตรงไปตรงมา
- [ ] เตรียมพร้อมวันชี้สองสถานและวันสืบพยาน (บัญชีระบุพยาน เอกสาร พยานบุคคล)
- [ ] ประเมินทางเลือกไกล่เกลี่ย/ยอมความตามความเป็นจริง
- [ ] คำแถลงการณ์ปิดคดีอ้างเฉพาะพยานหลักฐานที่อยู่ในสำนวนจริง
- [ ] มีแผนสำรองเมื่อพยานหรือประเด็นไม่เป็นไปตามคาด
