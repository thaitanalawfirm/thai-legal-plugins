# fact_gathering.md — การเก็บข้อเท็จจริงและจัดทำลำดับเหตุการณ์

อ่านไฟล์นี้เมื่อต้องเก็บและจัดระเบียบข้อเท็จจริงจากผู้มาปรึกษา

---

## สารบัญ
1. กรอบการเก็บข้อเท็จจริง
2. การจัดทำลำดับเหตุการณ์ (Timeline)
3. การเก็บข้อมูลคู่กรณีและผู้เกี่ยวข้อง
4. การเก็บและจัดการเอกสาร
5. การแยกข้อเท็จจริงออกจากความเห็น/การคาดเดา

---

## 1. กรอบการเก็บข้อเท็จจริง

เก็บให้ครบตามกรอบ **ใคร–ทำอะไร–ที่ไหน–เมื่อไร–อย่างไร–เพราะอะไร**:
- **ใคร** — บุคคล/นิติบุคคลที่เกี่ยวข้องทั้งหมด ความสัมพันธ์ระหว่างกัน
- **ทำอะไร** — เหตุการณ์/การกระทำที่เป็นต้นเรื่อง
- **ที่ไหน** — สถานที่เกิดเหตุ (สำคัญต่อเขตอำนาจศาล)
- **เมื่อไร** — วันเวลาของแต่ละเหตุการณ์ (สำคัญที่สุดต่อการคำนวณกำหนดเวลา/อายุความ)
- **อย่างไร** — ลำดับและรายละเอียดของเหตุการณ์
- **เพราะอะไร** — มูลเหตุ/ความต้องการของผู้มาปรึกษา

## 2. การจัดทำลำดับเหตุการณ์ (Timeline)

- เรียงเหตุการณ์ **ตามวันที่** จากเก่าไปใหม่
- ระบุวันที่ให้แม่นที่สุด — ถ้าจำได้แค่เดือน/ปี ให้บันทึกตามนั้นและทำเครื่องหมายว่าต้องยืนยัน
- **วันที่สำคัญที่ต้องเน้น:** วันเกิดเหตุ/วันทำสัญญา/วันผิดนัด/วันรู้เหตุ/วันได้รับเอกสาร —
  เพราะเป็นจุดเริ่มนับอายุความและกำหนดเวลา (ส่งต่อ `thai-litigation-deadlines`)
- Timeline ที่ชัดช่วยให้เห็นช่องว่างของเรื่องและประเด็นที่ต้องถามเพิ่ม

แม่แบบ timeline:
```
| วันที่ | เหตุการณ์ | เอกสาร/พยานที่เกี่ยวข้อง | หมายเหตุ |
|--------|-----------|---------------------------|----------|
| [วันที่] | [เหตุการณ์] | [เอกสาร] | [ต้องยืนยัน/สำคัญต่อกำหนดเวลา] |
```

## 3. การเก็บข้อมูลคู่กรณีและผู้เกี่ยวข้อง

เก็บรายชื่อ **ทุกคน/ทุกนิติบุคคล** ที่เกี่ยวข้อง:
- คู่กรณี (ฝ่ายตรงข้าม) — ชื่อเต็ม ที่อยู่ ความเกี่ยวพัน
- บุคคลที่สาม พยาน ผู้เกี่ยวข้องอื่น
- **เหตุผลสำคัญ:** รายชื่อนี้ใช้ตรวจผลประโยชน์ขัดกัน (`thai-conflict-check`) — เก็บให้ครบ
  ตั้งแต่ต้น

## 4. การเก็บและจัดการเอกสาร

- ทำรายการเอกสารที่ผู้มาปรึกษามี และที่ยังต้องขอ
- ระบุเอกสารสำคัญตามประเภทเรื่อง (ดู `matter_types.md`)
- เตือนเรื่อง **ต้นฉบับ** สำหรับเอกสารที่อาจต้องใช้เป็นพยานในคดี
- บันทึกว่าเอกสารใดได้รับแล้ว/รอรับ

## 5. การแยกข้อเท็จจริงออกจากความเห็น/การคาดเดา

- บันทึก **ข้อเท็จจริง** (สิ่งที่เกิดขึ้นจริงตามที่ผู้มาปรึกษารู้เห็น) แยกจาก **ความเห็น/
  การคาดเดา** ของผู้มาปรึกษา
- ระบุว่าข้อเท็จจริงใดผู้มาปรึกษ ารู้เห็นเอง ข้อใดได้ยินมา (เพื่อประเมินน้ำหนักภายหลัง)
- สิ่งที่ผู้มาปรึกษา "เชื่อว่า" หรือ "คิดว่า" ให้บันทึกแยกและทำเครื่องหมายว่าต้องตรวจสอบ

## Checklist การเก็บข้อเท็จจริง
- [ ] ครบกรอบ ใคร-ทำอะไร-ที่ไหน-เมื่อไร-อย่างไร-เพราะอะไร
- [ ] มี timeline เรียงตามวันที่ พร้อมเน้นวันที่สำคัญต่อกำหนดเวลา
- [ ] รายชื่อคู่กรณีและผู้เกี่ยวข้องครบ (สำหรับ conflict check)
- [ ] รายการเอกสารที่มี/ที่ต้องขอ
- [ ] แยกข้อเท็จจริงออกจากความเห็น/การคาดเดา
