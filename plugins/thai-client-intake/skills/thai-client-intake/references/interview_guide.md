# interview_guide.md — เทคนิคการสัมภาษณ์ลูกความ

อ่านไฟล์นี้เมื่อเตรียมหรือดำเนินการสัมภาษณ์ผู้มาปรึกษา

---

## สารบัญ
1. เป้าหมายของการสัมภาษณ์
2. การเปิดการสัมภาษณ์
3. เทคนิคการถาม
4. การรับมือสถานการณ์ที่ยาก
5. การปิดการสัมภาษณ์

---

## 1. เป้าหมายของการสัมภาษณ์

การสัมภาษณ์รับเรื่องมีเป้าหมายสามอย่างพร้อมกัน:
- **ได้ข้อเท็จจริงครบและถูกต้อง** เพื่อประเมินเรื่อง
- **เข้าใจสิ่งที่ผู้มาปรึกษาต้องการจริง ๆ** (เป้าหมาย ไม่ใช่แค่ปัญหา)
- **สร้างความไว้วางใจ** บนพื้นฐานความเป็นมืออาชีพ โดยไม่รับปากเกินจริง

## 2. การเปิดการสัมภาษณ์

- แนะนำตัวและอธิบายว่าการพูดคุยนี้เป็นการ **ปรึกษาเบื้องต้น** ยังไม่ใช่การรับเป็นลูกความ
- แจ้งเรื่อง **ความลับ** ว่าข้อมูลที่ให้จะถูกเก็บเป็นความลับ
- แจ้งสั้น ๆ ว่าจะเก็บข้อมูลส่วนบุคคลเพื่อพิจารณาเรื่อง (PDPA)
- เปิดด้วยคำถามกว้างให้ผู้มาปรึกษาเล่าเรื่องด้วยคำพูดของตนเองก่อน

## 3. เทคนิคการถาม

- **เริ่มด้วยคำถามปลายเปิด** — "ช่วยเล่าเรื่องที่เกิดขึ้นตั้งแต่ต้นให้ฟังหน่อย" เพื่อให้ได้
  ภาพรวมและรายละเอียดที่ผู้มาปรึกษาคิดว่าสำคัญ
- **ตามด้วยคำถามเจาะจง** เพื่อเก็บรายละเอียดที่ขาด — วันที่ จำนวนเงิน ชื่อบุคคล เอกสาร
- **ถามตามลำดับเวลา** เพื่อสร้าง timeline (ดู `fact_gathering.md`)
- **อย่าชี้นำคำตอบ** — ถามอย่างเป็นกลาง ไม่ใส่ความเห็นของเราเข้าไปในคำถาม
- **ฟังให้มาก พูดให้น้อย** ในชั้นนี้ หน้าที่คือเก็บข้อมูล ไม่ใช่บรรยายกฎหมาย
- **ทวนความเข้าใจเป็นระยะ** — สรุปสิ่งที่ได้ยินให้ผู้มาปรึกษายืนยัน เพื่อกันความเข้าใจผิด
- **ถามถึงเอกสาร** — มีเอกสารอะไรบ้าง อยู่ที่ไหน นำมาได้หรือไม่

## 4. การรับมือสถานการณ์ที่ยาก

- **ผู้มาปรึกษาเล่าวกวน/อารมณ์** — รับฟังด้วยความเข้าใจ แล้วค่อย ๆ ดึงกลับสู่ลำดับเหตุการณ์
- **ข้อเท็จจริงที่ไม่เป็นผลดีต่อผู้มาปรึกษา** — ต้องเก็บให้ครบเช่นกัน อย่าเลี่ยง เพราะกระทบ
  การประเมิน อธิบายว่าทนายต้องรู้ทั้งด้านดีและด้านเสียจึงช่วยได้
- **ผู้มาปรึกษาถามว่า "ชนะไหม"** — ตอบตามกรอบ: ยังให้คำตอบชี้ขาดไม่ได้จนกว่าจะดูข้อเท็จจริง
  และเอกสารครบ ไม่รับปากผล
- **ผู้มาปรึกษาเปิดเผยเจตนาที่อาจผิดกฎหมาย** — ไม่ช่วยวางแผนทำผิด และพิจารณากรอบจริยธรรม

## 5. การปิดการสัมภาษณ์

- ทวนสรุปข้อเท็จจริงสำคัญและสิ่งที่ผู้มาปรึกษาต้องการ
- ระบุ **เอกสารที่ขอให้นำมาเพิ่ม** และข้อมูลที่ยังขาด
- อธิบาย **ขั้นตอนถัดไป** — สำนักงานจะตรวจสอบ (รวมถึง conflict) และแจ้งเรื่องการรับงานและ
  ค่าวิชาชีพ ก่อนเริ่มดำเนินการ
- **ไม่รับปากผลหรือรับปากรับงานทันที** ในชั้นนี้ เว้นแต่มีเหตุเร่งด่วนเรื่องกำหนดเวลาที่
  ต้องตัดสินใจโดยทนายผู้รับผิดชอบ
- หากมีประเด็นเร่งด่วน (อายุความใกล้หมด) แจ้งให้ผู้มาปรึกษาทราบความเร่งด่วนและรีบส่งต่อ

## Checklist การสัมภาษณ์
- [ ] เปิดด้วยการอธิบายสถานะปรึกษาเบื้องต้น + ความลับ
- [ ] ใช้คำถามปลายเปิดก่อน แล้วเจาะจง
- [ ] เก็บข้อเท็จจริงทั้งด้านดีและด้านเสีย
- [ ] ทวนความเข้าใจเป็นระยะ
- [ ] ระบุเอกสารที่ต้องขอเพิ่ม
- [ ] ปิดด้วยขั้นตอนถัดไป โดยไม่รับปากผล
