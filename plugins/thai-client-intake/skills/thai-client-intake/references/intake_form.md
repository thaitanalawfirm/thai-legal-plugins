# intake_form.md — แม่แบบแบบฟอร์มรับเรื่องและบันทึกสัมภาษณ์

ใช้แม่แบบเหล่านี้บันทึกการรับเรื่อง ปรับตามประเภทเรื่อง (ดู `matter_types.md`)

> ทำเครื่องหมาย [....] ทุกจุดที่ต้องเติม และทำเครื่องหมาย 📝 ข้อมูลที่ยังต้องยืนยัน

---

## 1. แม่แบบแบบฟอร์มรับเรื่อง (Intake Form)

```
แบบฟอร์มรับเรื่อง — สำนักงาน [ชื่อ]
วันที่รับเรื่อง: [....]   ผู้รับเรื่อง: [....]

ก. ข้อมูลผู้มาปรึกษา
   - ชื่อ-นามสกุล / ชื่อนิติบุคคล: [....]
   - กรณีนิติบุคคล ผู้มีอำนาจสั่งงาน: [....]
   - ข้อมูลติดต่อ: [....]
   - สถานะ: ผู้มาปรึกษา (ยังไม่รับเป็นลูกความจนกว่าจะลงนามหนังสือว่าจ้าง)

ข. คู่กรณีและผู้เกี่ยวข้อง (สำหรับตรวจ conflict)
   - คู่กรณี: [....]
   - ผู้เกี่ยวข้องอื่น: [....]

ค. ประเภทเรื่อง
   - [แพ่ง-สัญญา / แพ่ง-ละเมิด / อาญา / แรงงาน / ครอบครัว-มรดก / ที่ดิน / ที่ปรึกษา / อื่น ๆ]
   - มิติอื่นของเรื่อง (ถ้ามี): [....]

ง. สรุปข้อเท็จจริง
   [สรุปเรื่องโดยย่อ]

จ. ลำดับเหตุการณ์ (Timeline)
   | วันที่ | เหตุการณ์ | เอกสาร/พยาน | หมายเหตุ |
   | ... | ... | ... | ... |

ฉ. สิ่งที่ผู้มาปรึกษาต้องการ
   [เป้าหมาย/ผลที่ต้องการ]

ช. เอกสาร
   - ได้รับแล้ว: [....]
   - ต้องขอเพิ่ม: [....]

ซ. ประเด็นเร่งด่วน
   🔴 [อายุความ/กำหนดเวลา/อื่น ๆ ที่ต้องทำทันที — หรือ "ไม่พบในชั้นนี้"]

ฌ. ประเมินเบื้องต้น (ไม่ใช่ความเห็นชี้ขาด)
   [ภาพรวมเชิงข้อสังเกต]

ญ. ขั้นตอนถัดไป
   [ ] ตรวจผลประโยชน์ขัดกัน (conflict check)
   [ ] จัดทำหนังสือว่าจ้างและกำหนดค่าวิชาชีพ
   [ ] เปิดสำนวนและมอบหมายผู้รับผิดชอบ
```

## 2. แม่แบบบันทึกสรุปการสัมภาษณ์ (Intake Summary)

```
บันทึกสรุปการรับเรื่อง

ผู้มาปรึกษา: [....]    วันที่: [....]    ผู้สัมภาษณ์: [....]
ประเภทเรื่อง: [....]

1. สรุปเรื่อง
   [เล่าเรื่องโดยย่อตามลำดับเหตุการณ์]

2. ข้อเท็จจริงสำคัญ
   [รายการข้อเท็จจริงที่ได้ แยกข้อเท็จจริงออกจากความเห็น/การคาดเดาของผู้มาปรึกษา]

3. คู่กรณีและผู้เกี่ยวข้อง
   [รายชื่อครบสำหรับ conflict check]

4. ประเด็นเร่งด่วน
   🔴 [ระบุ หรือ "ไม่พบในชั้นนี้"]

5. ประเมินเบื้องต้น
   [ข้อสังเกต ไม่ฟันธง]

6. ข้อมูล/เอกสารที่ยังต้องเก็บ
   📝 [รายการ]

7. ขั้นตอนถัดไปที่แนะนำ
   [conflict check → หนังสือว่าจ้าง → เริ่มงาน]

หมายเหตุ: เป็นบันทึกเบื้องต้นบนข้อมูลที่ได้รับ เป็นร่างให้ทนายผู้รับผิดชอบตรวจ
ยังไม่ถือเป็นการรับเป็นลูกความหรือการให้ความเห็นทางกฎหมายชี้ขาด
```

---

## ข้อควรจำ
- เก็บรายชื่อคู่กรณี/ผู้เกี่ยวข้องให้ครบ — เป็นหัวใจของการส่งต่อ conflict check
- เน้นวันที่สำคัญทุกจุดเพื่อจับกำหนดเวลา
- ไม่ใส่คำรับปากผลในบันทึก
- ปิดท้ายด้วย "ข้อสังเกตจากทนาย" ตามมาตรฐานของสกิลนี้
