อ่านไฟล์นี้เมื่อต้องประเมินเรื่องเบื้องต้นหลังเก็บข้อเท็จจริง

> ⚠️ การประเมินเบื้องต้น **ไม่ใช่ความเห็นทางกฎหมายชี้ขาด** — เป็นการตั้งข้อสังเกตเพื่อ
> ตัดสินใจรับงานและวางขั้นตอน หากต้องการความเห็นเต็มรูป ใช้ `thai-legal-opinion`

## 1. ขอบเขตของการประเมินเบื้องต้น

การประเมินเบื้องต้นตอบคำถามเชิงบริหารงาน ไม่ใช่เชิงวินิจฉัยชี้ขาด:
- เรื่องนี้เป็นเรื่องประเภทใด อยู่ในความเชี่ยวชาญของสำนักงานหรือไม่
- มีประเด็นเร่งด่วนที่ต้องทำทันทีหรือไม่
- ข้อมูล/เอกสารพอจะประเมินต่อหรือยัง ขาดอะไร
- มีอุปสรรคหรือธงเตือนในการรับงานหรือไม่ (รวมถึง conflict)

**ไม่ทำในชั้นนี้:** วินิจฉัยชี้ขาดว่าชนะ/แพ้ ให้ความเห็นทางกฎหมายแบบฟันธง รับปากผล

## 2. การจับประเด็นเร่งด่วน

นี่คือส่วนสำคัญที่สุดของการประเมินเบื้องต้น — ประเด็นที่พลาดแล้วเสียหายถาวร:
- **อายุความ/กำหนดเวลาที่ใกล้หมด** — ตรวจวันที่สำคัญจาก timeline แล้วประเมินคร่าว ๆ ว่า
  ใกล้กำหนดหรือไม่ → ส่งต่อ `thai-litigation-deadlines` เพื่อคำนวณแม่นยำ
- **กำหนดร้องทุกข์ 3 เดือน** (คดีอาญาความผิดอันยอมความได้)
- **กำหนดยื่นเอกสารในคดีที่ค้างอยู่** (เช่น ผู้มาปรึกษาถูกฟ้องและใกล้ครบกำหนดยื่นคำให้การ
  หรือใกล้ครบกำหนดอุทธรณ์)
- **เหตุที่ต้องรักษาสิทธิทันที** เช่น ขอคุ้มครองชั่วคราว

**หากพบประเด็นเร่งด่วน ให้เตือนเป็นอันดับแรกสุดและแจ้งทนายผู้รับผิดชอบทันที** แม้ยังไม่ได้
ลงนามหนังสือว่าจ้าง ก็ต้องตัดสินใจเรื่องการรักษาสิทธิโดยทนายผู้รับผิดชอบ

## 3. การประเมินความเหมาะสมในการรับงาน

ตั้งข้อสังเกตเพื่อให้ทนายตัดสินใจรับ/ไม่รับ:
- **อยู่ในความเชี่ยวชาญ** ของสำนักงานหรือไม่
- **มีผลประโยชน์ขัดกัน** ที่เห็นเบื้องต้นหรือไม่ → ต้องตรวจ `thai-conflict-check`
- **ความเป็นไปได้และความคาดหวังของผู้มาปรึกษา** สอดคล้องกับความเป็นจริงหรือไม่
- **ธงเตือน** เช่น ผู้มาปรึกษาต้องการให้ทำสิ่งที่ผิดกฎหมาย/ผิดจริยธรรม เคยเปลี่ยนทนายหลายครั้ง
  มีปัญหาเรื่องการสื่อสารข้อเท็จจริง

## 4. ผลลัพธ์ของการประเมิน

สรุปการประเมินเบื้องต้นเป็น:
- **ประเภทเรื่องและภาพรวม** — เรื่องนี้คืออะไรในเชิงกฎหมาย (ระดับข้อสังเกต ไม่ฟันธง)
- **ประเด็นเร่งด่วน** — สิ่งที่ต้องทำทันที (ถ้ามี)
- **ข้อมูล/เอกสารที่ยังต้องเก็บ** ก่อนประเมินลึก
- **ข้อสังเกตเรื่องการรับงาน** — รวมถึงสิ่งที่ต้องตรวจก่อนรับ (conflict)
- **ขั้นตอนถัดไปที่แนะนำ**

> ระบุเสมอว่าเป็นการประเมินเบื้องต้นบนข้อมูลที่ได้รับ ไม่ใช่ความเห็นทางกฎหมายชี้ขาด และเป็น
> ร่างให้ทนายผู้รับผิดชอบพิจารณา
