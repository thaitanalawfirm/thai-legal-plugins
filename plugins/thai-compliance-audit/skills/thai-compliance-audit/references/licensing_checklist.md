# licensing_checklist.md — ใบอนุญาตและการกำกับดูแลเฉพาะธุรกิจ

ใช้ไฟล์นี้ตรวจว่าองค์กรมีใบอนุญาตที่จำเป็นครบและปฏิบัติตามเงื่อนไขหรือไม่

> ⚠️ ใบอนุญาตและเงื่อนไขขึ้นกับประเภทธุรกิจและเปลี่ยนแปลงได้ ต้องตรวจกับหน่วยงานเจ้าของ
> เรื่องและกฎหมายเฉพาะฉบับปัจจุบันเสมอ — สกิลนี้ให้กรอบการตรวจ ไม่ใช่รายการใบอนุญาตครบทุก
> ธุรกิจ

---

## 1. ระบุกิจกรรมที่ต้องขออนุญาต
- ทำรายการกิจกรรมทางธุรกิจขององค์กรทั้งหมด
- เทียบกับกฎหมายว่ากิจกรรมใดต้อง **ขออนุญาต / จดทะเบียน / แจ้ง** ก่อนดำเนินการ
- ครอบคลุมทั้งใบอนุญาตประกอบกิจการหลัก และใบอนุญาตเฉพาะกิจกรรม (เช่น โฆษณา นำเข้า ส่งออก)

## 2. ตรวจสถานะใบอนุญาตที่มี
- [ ] มีใบอนุญาตครบทุกกิจกรรมที่กฎหมายกำหนดให้ต้องมี
- [ ] ใบอนุญาตทุกใบ **ยังไม่หมดอายุ** และมีแผนต่ออายุล่วงหน้า
- [ ] ใบอนุญาตออกในชื่อนิติบุคคล/สถานประกอบการที่ถูกต้องตรงปัจจุบัน
- [ ] ขอบเขตที่ได้รับอนุญาตครอบคลุมกิจกรรมที่ทำจริง (ไม่ทำเกินขอบเขต)

## 3. ตรวจการปฏิบัติตามเงื่อนไขใบอนุญาต
- [ ] ปฏิบัติตามเงื่อนไขที่แนบมากับใบอนุญาต (เช่น มาตรฐานสถานที่ การรายงาน การต่ออายุ)
- [ ] ยื่นรายงาน/แบบที่หน่วยงานกำกับกำหนดตามกำหนดเวลา
- [ ] มีบุคลากรที่มีคุณสมบัติ/ใบอนุญาตเฉพาะตามที่กฎหมายกำหนด (ถ้ามี)

## 4. การเปลี่ยนแปลงที่ต้องแจ้ง/ขออนุมัติ
- [ ] กรณีเปลี่ยนแปลงสำคัญ (ที่ตั้ง ผู้มีอำนาจ ขอบเขตกิจการ โครงสร้างผู้ถือหุ้น) ได้แจ้ง/
      ขออนุมัติตามที่กฎหมายกำหนด
- [ ] ตรวจว่าใบอนุญาต **คงอยู่หรือต้องขอใหม่เมื่อเปลี่ยนผู้ถือหุ้น/อำนาจควบคุม** (สำคัญต่อ
      ธุรกรรม M&A — เชื่อมกับ `thai-legal-due-diligence`)

## 5. ประวัติการกำกับดูแล
- [ ] ตรวจประวัติการถูกตักเตือน ปรับ พักใช้ หรือเพิกถอนใบอนุญาต
- [ ] มีข้อโต้แย้ง/คำสั่งทางปกครองที่ค้างอยู่หรือไม่

---

## หมวดใบอนุญาตที่พบบ่อย (เป็นตัวอย่าง ไม่ใช่รายการครบ)
- ใบอนุญาตประกอบกิจการตามประเภทธุรกิจ (เช่น โรงงาน สถานบริการ สถานประกอบการอาหาร)
- ใบอนุญาต/การขึ้นทะเบียนด้านอาหารและยา เครื่องสำอาง เครื่องมือแพทย์ (หากเกี่ยวข้อง)
- ใบอนุญาตด้านสิ่งแวดล้อม การจัดการของเสีย (หากเกี่ยวข้อง)
- ใบอนุญาตด้านการเงิน/การประกอบธุรกิจที่อยู่ภายใต้การกำกับเฉพาะ (หากเกี่ยวข้อง)
- ใบอนุญาตเฉพาะกิจกรรม เช่น โฆษณา นำเข้า-ส่งออก ขนส่ง

> สำหรับแต่ละธุรกิจ ต้องระบุกฎหมายและหน่วยงานเจ้าของเรื่องที่ใช้บังคับจริง และตรวจรายการ
> ใบอนุญาตที่จำเป็นกับหน่วยงานนั้น — ห้ามสรุปรายการใบอนุญาตจากความจำโดยไม่ตรวจ

## หลักการใช้ checklist นี้
- เริ่มจากการ map กิจกรรมธุรกิจ → กฎหมาย/ใบอนุญาตที่ใช้บังคับ
- เทียบสถานะจริงกับสิ่งที่ต้องมี บันทึก ผ่าน / ไม่ผ่าน / ต้องตรวจเพิ่ม
- การประกอบกิจการโดยไม่มีใบอนุญาตที่จำเป็นเป็นความเสี่ยงระดับสูง (มีโทษและกระทบการดำเนินงาน)
- ส่งช่องว่างที่พบไปจัดระดับใน `risk_and_remediation.md`
