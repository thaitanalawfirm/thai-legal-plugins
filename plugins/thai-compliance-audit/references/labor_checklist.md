# labor_checklist.md — การปฏิบัติตามกฎหมายแรงงาน

ใช้ checklist นี้ตรวจการปฏิบัติตามกฎหมายแรงงานขององค์กรที่มีลูกจ้าง

> ⚠️ อ้างตัวบทระดับ A จากคลัง: พ.ร.บ.คุ้มครองแรงงาน, พ.ร.บ.ประกันสังคม, พ.ร.บ.เงินทดแทน,
> พ.ร.บ.แรงงานสัมพันธ์ · **อัตราต่าง ๆ (ค่าจ้างขั้นต่ำ เงินสมทบ) เปลี่ยนบ่อย ต้องตรวจฉบับ
> ปัจจุบันและระบุวันที่อ้างอิง — ห้ามใส่ตัวเลขจากความจำ**

---

## 1. เอกสารและทะเบียนพื้นฐาน
- [ ] มี **ข้อบังคับเกี่ยวกับการทำงาน** (ตามเงื่อนไขจำนวนลูกจ้างที่กฎหมายกำหนด) และปิด
      ประกาศ/เผยแพร่ให้ลูกจ้างทราบ
- [ ] มี **ทะเบียนลูกจ้าง** และเอกสารเกี่ยวกับการจ่ายค่าจ้างตามที่กฎหมายกำหนด
- [ ] สัญญาจ้างมีสาระสำคัญครบและไม่มีข้อกำหนดที่ขัดกฎหมายคุ้มครองแรงงาน

## 2. ค่าจ้างและเวลาทำงาน
- [ ] จ่ายค่าจ้างไม่ต่ำกว่า **อัตราค่าจ้างขั้นต่ำ** (📝 ตรวจอัตราปัจจุบันตามจังหวัด)
- [ ] เวลาทำงานปกติและการพักไม่เกินที่กฎหมายกำหนด
- [ ] จ่ายค่าล่วงเวลา ค่าทำงานในวันหยุด และค่าล่วงเวลาในวันหยุด ตามอัตราที่กฎหมายกำหนด
- [ ] วันหยุดประจำสัปดาห์ วันหยุดตามประเพณี และวันหยุดพักผ่อนประจำปี ครบตามกฎหมาย

## 3. วันลาและสวัสดิการ
- [ ] ให้สิทธิการลาตามกฎหมาย (ลาป่วย ลากิจ ลาคลอด ลาเพื่อกิจธุระอื่นตามที่กฎหมายกำหนด)
- [ ] จัดสวัสดิการขั้นต่ำตามที่กฎหมายกำหนด

## 4. ประกันสังคมและเงินทดแทน
- [ ] ขึ้นทะเบียนนายจ้าง/ลูกจ้างกับประกันสังคม และนำส่งเงินสมทบครบ (📝 ตรวจอัตราปัจจุบัน)
- [ ] จัดให้มีกองทุนเงินทดแทนตามกฎหมาย
- [ ] ปฏิบัติตามหน้าที่เมื่อเกิดอุบัติเหตุ/เจ็บป่วยจากการทำงาน

## 5. ความปลอดภัยในการทำงาน
- [ ] ปฏิบัติตามกฎหมายความปลอดภัย อาชีวอนามัย และสภาพแวดล้อมในการทำงาน
- [ ] มีเจ้าหน้าที่ความปลอดภัย/คณะกรรมการความปลอดภัย ตามเงื่อนไขที่กฎหมายกำหนด

## 6. การเลิกจ้างและค่าชดเชย
- [ ] เข้าใจหลักเกณฑ์ **ค่าชดเชย** ตามอายุงาน และ **ค่าชดเชยพิเศษ** กรณีเฉพาะ (📝 ตรวจ
      อัตราและขั้นบันไดปัจจุบัน)
- [ ] กระบวนการเลิกจ้างเป็นธรรมและมีเหตุตามกฎหมาย (ลดความเสี่ยงคดีเลิกจ้างไม่เป็นธรรม)
- [ ] กรณีบอกกล่าวล่วงหน้า/จ่ายแทนการบอกกล่าว ปฏิบัติถูกต้อง

## 7. แรงงานสัมพันธ์ (ถ้ามี)
- [ ] ปฏิบัติตามกฎหมายแรงงานสัมพันธ์ กรณีมีสหภาพ/ข้อตกลงเกี่ยวกับสภาพการจ้าง
- [ ] กระบวนการเปลี่ยนแปลงสภาพการจ้างเป็นไปตามกฎหมาย

## 8. กรณีเฉพาะ
- [ ] การจ้างแรงงานต่างด้าวมีใบอนุญาตทำงานถูกต้อง (หากมี)
- [ ] การจ้างเหมาค่าแรง/ผู้รับเหมาช่วง ปฏิบัติตามกฎหมาย

---

## เอกสารหลักที่ควรมี
- ข้อบังคับเกี่ยวกับการทำงาน
- ทะเบียนลูกจ้างและเอกสารการจ่ายค่าจ้าง
- สัญญาจ้างที่สอดคล้องกฎหมาย
- เอกสารขึ้นทะเบียนและนำส่งประกันสังคม/เงินทดแทน
- เอกสารด้านความปลอดภัยในการทำงาน

## หลักการใช้ checklist นี้
- เทียบแต่ละข้อกับสถานะจริง บันทึก ผ่าน / ไม่ผ่าน / ต้องตรวจเพิ่ม
- อ้างมาตราจากคลังระดับ A
- ทุกข้อที่มีเครื่องหมาย 📝 = ตัวเลข/อัตราที่ต้องยืนยันกับฉบับปัจจุบัน ระบุวันที่อ้างอิง
- ภาระค่าชดเชยจากการเลิกจ้างเป็นความเสี่ยงทางการเงินที่สำคัญ — ประเมินให้ชัด
- ส่งช่องว่างที่พบไปจัดระดับใน `risk_and_remediation.md`
