# supreme_court.md — ชั้นฎีกา

คลังอ้างอิงสำหรับร่างฎีกา คำร้องขออนุญาตฎีกา และคำแก้ฎีกา

> ⚠️ เลขมาตราและหลักเกณฑ์เป็นแนวอ้างอิงตาม ป.วิ.พ. และ ป.วิ.อาญา ระบบการฎีกามีการแก้ไข
> สำคัญ **ให้ทนายผู้รับผิดชอบยืนยันกับตัวบทฉบับปัจจุบันก่อนยื่นเสมอ**

---

## สารบัญ
1. ระบบการฎีกาคดีแพ่ง — ฎีกาเมื่อได้รับอนุญาต
2. คำร้องขออนุญาตฎีกา
3. ฎีกา (คำฟ้องฎีกา)
4. การฎีกาคดีอาญา
5. คำแก้ฎีกา
6. แม่แบบ

---

## 1. ระบบการฎีกาคดีแพ่ง — ฎีกาเมื่อได้รับอนุญาต

ระบบการฎีกาคดีแพ่งของไทยได้เปลี่ยนเป็นระบบ **"ฎีกาได้เมื่อได้รับอนุญาต"** กล่าวคือ คู่ความ
ที่ประสงค์จะฎีกาคำพิพากษา/คำสั่งของศาลอุทธรณ์ โดยหลักต้อง **ยื่นคำร้องขออนุญาตฎีกาต่อ
ศาลฎีกา** พร้อมกับฎีกา และศาลฎีกาจะพิจารณาว่าจะอนุญาตให้ฎีกาหรือไม่

ศาลฎีกาจะอนุญาตเมื่อปัญหาตามฎีกาเป็น **ปัญหาสำคัญที่ศาลฎีกาควรวินิจฉัย** เช่น เป็นปัญหาที่
เกี่ยวพันกับประโยชน์สาธารณะ เป็นปัญหาที่คำพิพากษาศาลอุทธรณ์ขัดกันเอง หรือเป็นปัญหาสำคัญอื่น
— **ต้องตรวจหลักเกณฑ์การอนุญาตตามตัวบทฉบับปัจจุบัน**

> ระบบและรายละเอียดของการขออนุญาตอาจต่างกันในคดีแต่ละประเภท (เช่น คดีผู้บริโภค คดีแรงงาน
> มีระบบเฉพาะ) — ตรวจกฎหมายวิธีพิจารณาที่ใช้กับคดีนั้น

## 2. คำร้องขออนุญาตฎีกา

**สาระสำคัญที่ต้องบรรยาย:**
1. คดีนี้ศาลชั้นต้นและศาลอุทธรณ์พิพากษาว่าอย่างไร
2. ปัญหาที่ผู้ร้องประสงค์จะฎีกาคืออะไร
3. **เหตุผลที่แสดงว่าปัญหานั้นเป็นปัญหาสำคัญที่ศาลฎีกาควรวินิจฉัย** ตามหลักเกณฑ์ที่กฎหมาย
   กำหนด — นี่คือหัวใจของคำร้อง
**คำขอ:** ขอให้ศาลฎีกาอนุญาตให้ผู้ร้องฎีกา
**ข้อควรระวัง:** ยื่นพร้อมฎีกาภายในกำหนดเวลาฎีกา — ตรวจกำหนดและวิธียื่นตามตัวบทปัจจุบัน

## 3. ฎีกา (คำฟ้องฎีกา)

**กำหนดเวลา:** โดยทั่วไปยื่นภายใน **1 เดือน** นับแต่วันที่ได้อ่านหรือถือว่าได้อ่านคำพิพากษา/
คำสั่งศาลอุทธรณ์ — หากไม่พร้อม พิจารณายื่นคำร้องขอขยายระยะเวลาก่อนครบกำหนด
**สาระสำคัญที่ต้องบรรยาย:**
1. ลำดับผลคำพิพากษาของศาลชั้นต้นและศาลอุทธรณ์
2. **คัดค้านคำวินิจฉัยของศาลอุทธรณ์เป็นข้อ ๆ** ว่าวินิจฉัยผิดพลาดอย่างไร
3. คำขอให้ศาลฎีกาพิพากษาไปในทางใด
**หลักสำคัญ:** ฎีกาได้เฉพาะข้อที่ **ยกขึ้นว่ากันมาแล้วโดยชอบในศาลชั้นต้นและศาลอุทธรณ์**
เว้นแต่ปัญหาข้อกฎหมายอันเกี่ยวด้วยความสงบเรียบร้อย / ฎีกาในปัญหาข้อเท็จจริงมีข้อจำกัด
เช่นเดียวกับชั้นอุทธรณ์ — ตรวจก่อนเสมอ

## 4. การฎีกาคดีอาญา

- การฎีกาในปัญหาข้อเท็จจริงในคดีอาญามีข้อห้ามตามอัตราโทษและตามผลที่ศาลชั้นต้นกับศาลอุทธรณ์
  พิพากษา (เช่น กรณีศาลล่างทั้งสองพิพากษาต้องกันมีข้อจำกัดมากขึ้น) — ตรวจหลักเกณฑ์ตาม
  ป.วิ.อาญา ฉบับปัจจุบัน
- กรณีต้องห้ามฎีกา อาจมีช่องทางขอให้ผู้พิพากษาซึ่งพิจารณาคดีรับรอง หรืออัยการสูงสุดรับรอง
  ให้ฎีกา ตามที่กฎหมายกำหนด — ตรวจเงื่อนไข

## 5. คำแก้ฎีกา

**ใช้เมื่อ:** คู่ความอีกฝ่ายยื่นฎีกา ฝ่ายที่ถูกฎีกายื่นคำแก้ฎีกาเพื่อโต้แย้ง
**สาระสำคัญที่ต้องบรรยาย:** โต้แย้งข้อฎีกาของอีกฝ่ายเป็นข้อ ๆ ให้ตรงกัน สนับสนุนว่าคำพิพากษา
ศาลอุทธรณ์ชอบแล้ว และหากมีประเด็นเรื่องการอนุญาตฎีกา อาจโต้แย้งว่าไม่ใช่ปัญหาสำคัญที่ศาล
ฎีกาควรวินิจฉัย
**กำหนดเวลา:** ยื่นภายในกำหนดนับแต่ได้รับสำเนาฎีกา — ตรวจกำหนด

## 6. แม่แบบ

### 6.1 แม่แบบคำฟ้องฎีกา

```
                          ศาลฎีกา
                          (ยื่นผ่านศาล[ชื่อศาลชั้นต้น])

[ชื่อ] ผู้ฎีกา (โจทก์/จำเลย)
[ชื่อ] ผู้ถูกฎีกา

เรื่อง  ฎีกาคำพิพากษาศาลอุทธรณ์

        คดีนี้ศาลชั้นต้นพิพากษาเมื่อวันที่ .... ว่า [ผล] ต่อมา
        ศาลอุทธรณ์พิพากษาเมื่อวันที่ .... ว่า [ผล]

        ผู้ฎีกาไม่เห็นพ้องด้วยกับคำพิพากษาศาลอุทธรณ์ ขอยื่นฎีกา
        คัดค้านดังต่อไปนี้

        ข้อ 1. [คัดค้านคำวินิจฉัยของศาลอุทธรณ์ประเด็นแรก]

        ข้อ 2. [คัดค้านประเด็นต่อไป]

        ขอศาลฎีกาได้โปรดพิพากษากลับ/แก้คำพิพากษาศาลอุทธรณ์ โดย [ผลที่ขอ]

                        ควรมิควรแล้วแต่จะโปรด
                        ลงชื่อ ......................... ผู้ฎีกา/ทนาย
```

### 6.2 แม่แบบคำร้องขออนุญาตฎีกา (ยื่นพร้อมฎีกา)

```
เรื่อง  คำร้องขออนุญาตฎีกา

        ข้าพเจ้า [ชื่อ] ผู้ฎีกา ขอประทานกราบเรียนว่า พร้อมคำร้องนี้
        ข้าพเจ้าได้ยื่นฎีกาคัดค้านคำพิพากษาศาลอุทธรณ์

        ปัญหาตามฎีกาของข้าพเจ้าเป็นปัญหาสำคัญที่ศาลฎีกาควรวินิจฉัย
        เพราะ [บรรยายเหตุผลตามหลักเกณฑ์การอนุญาต เช่น เป็นปัญหาที่
        กระทบประโยชน์สาธารณะ / คำพิพากษาขัดกัน / เป็นปัญหาสำคัญอื่น]

        ขอศาลฎีกาได้โปรดอนุญาตให้ข้าพเจ้าฎีกาในคดีนี้

                        ควรมิควรแล้วแต่จะโปรด
                        ลงชื่อ ......................... ผู้ร้อง/ทนาย
```

## Checklist ชั้นฎีกา
- [ ] ยื่นภายในกำหนด (โดยทั่วไป 1 เดือนนับแต่วันอ่านคำพิพากษาศาลอุทธรณ์)
- [ ] คดีแพ่ง — แนบคำร้องขออนุญาตฎีกา และบรรยายว่าเป็นปัญหาสำคัญที่ศาลฎีกาควรวินิจฉัย
- [ ] คดีอาญา — ตรวจข้อห้ามฎีกาข้อเท็จจริงตามอัตราโทษและผลคำพิพากษาศาลล่าง
- [ ] ฎีกาเฉพาะข้อที่ยกขึ้นว่ากันมาแล้วในศาลชั้นต้นและศาลอุทธรณ์
- [ ] คัดค้านคำวินิจฉัยศาลอุทธรณ์เป็นข้อ ๆ พร้อมเหตุผล
- [ ] เสียค่าขึ้นศาลชั้นฎีกาและค่าธรรมเนียมที่เกี่ยวข้องครบ
- [ ] คำแก้ฎีกา — โต้แย้งตรงข้อฎีกาและยื่นในกำหนด
