# motions_core.md — หลักร่วมและแม่แบบคำร้อง คำแถลง คำขอ

อ่านไฟล์นี้ก่อนร่างเอกสารทุกชนิดในสกิลนี้ เพราะเป็นรูปแบบและกรอบกระบวนการที่ใช้ร่วมกัน

> ⚠️ **คำเตือน:** เลขมาตราและกำหนดเวลาในไฟล์นี้เป็นแนวอ้างอิงตามประมวลกฎหมายวิธีพิจารณา
> ความแพ่งและความอาญา ซึ่งมีการแก้ไขเป็นระยะ **ให้ทนายผู้รับผิดชอบยืนยันกับตัวบทฉบับ
> ปัจจุบันก่อนยื่นเสมอ ห้ามประดิษฐ์เลขมาตราหรือคำพิพากษาฎีกา**

---

## สารบัญ
1. ความแตกต่างของคำร้อง คำแถลง คำขอ
2. คำร้องมีข้อพิพาท กับ คำร้องไม่มีข้อพิพาท
3. หลักเรื่องกำหนดเวลาและการขยายเวลา
4. แม่แบบคำร้อง
5. แม่แบบคำแถลง
6. หลักการเขียนเหตุผลในคำร้องที่ดี

---

## 1. ความแตกต่างของคำร้อง คำแถลง คำขอ

- **คำร้อง (motion/petition):** เอกสารที่ขอให้ศาล **มีคำสั่งอย่างใดอย่างหนึ่ง** เช่น
  ขอเลื่อนคดี ขอแก้ไขคำฟ้อง ขอคุ้มครองชั่วคราว — ศาลต้องมีคำสั่งตอบ
- **คำแถลง (statement):** เอกสารที่ **แจ้งข้อเท็จจริงหรือแสดงข้อมูลต่อศาล** โดยมิได้ขอให้
  ศาลมีคำสั่งโดยตรง เช่น คำแถลงเรื่องการส่งหมาย คำแถลงประกอบคำร้อง คำแถลงคัดค้าน
- **คำขอ (application):** ถ้อยคำส่วนที่ระบุสิ่งที่ขอ มักเป็นส่วนท้ายของคำร้อง — บางบริบท
  ใช้เรียกเอกสารเริ่มคดีไม่มีข้อพิพาท (ดูข้อ 2)

เลือกชนิดเอกสารให้ตรงกับสิ่งที่ต้องการ — หากต้องการให้ศาล "สั่ง" ต้องเป็นคำร้อง

## 2. คำร้องมีข้อพิพาท กับ คำร้องไม่มีข้อพิพาท

- **คำร้องระหว่างพิจารณา (ในคดีที่มีอยู่แล้ว):** ยื่นเข้าสำนวนคดีเดิม อ้างเลขคดีเดิม
- **คำร้องขอเริ่มคดีไม่มีข้อพิพาท:** เช่น ร้องขอตั้งผู้จัดการมรดก ร้องขอแสดงกรรมสิทธิ์ —
  เป็นการเริ่มคดีใหม่ ผู้ยื่นเรียก "ผู้ร้อง" (เอกสารเริ่มคดีกลุ่มนี้บางส่วนอยู่ในสกิล
  `thai-litigation-pleadings`)

## 3. หลักเรื่องกำหนดเวลาและการขยายเวลา

- กำหนดเวลาตามกฎหมาย (เช่น ยื่นอุทธรณ์/ฎีกาภายใน 1 เดือน ยื่นคำให้การภายใน 15 วัน) **สำคัญ
  ที่สุด** — พลาดคือเสียสิทธิ
- การ **ขยายระยะเวลา** ทำได้เมื่อมี **พฤติการณ์พิเศษ** และโดยหลักต้องยื่นคำร้องขอขยาย
  **ก่อนสิ้นกำหนดเดิม** เว้นแต่มีเหตุสุดวิสัย — ดู `interlocutory.md`
- ตรวจวันเริ่มนับเสมอ (เช่น อุทธรณ์นับแต่วันอ่านหรือถือว่าได้อ่านคำพิพากษา)

## 4. แม่แบบคำร้อง

```
                                        คดีหมายเลขดำที่ ........./...........
                                        คดีหมายเลขแดงที่ ........./...........

                          ศาล[ชื่อศาล]

[ชื่อโจทก์]                                                      โจทก์
        ระหว่าง
[ชื่อจำเลย]                                                      จำเลย

เรื่อง  [ระบุเรื่อง เช่น คำร้องขอเลื่อนการพิจารณา]

        ข้าพเจ้า [ชื่อผู้ยื่น] [โจทก์/จำเลย/ผู้ร้อง] ในคดีนี้
        ขอประทานกราบเรียนต่อศาลที่เคารพว่า

        ข้อ 1. [บรรยายข้อเท็จจริงและเหตุผลที่นำมาสู่การยื่นคำร้อง]

        ข้อ 2. [บรรยายเหตุผลสนับสนุนคำขอ พร้อมอ้างฐานกฎหมาย
        วิธีพิจารณาที่เกี่ยวข้อง]

        ด้วยเหตุดังกล่าว ขอศาลได้โปรด [ระบุคำขอให้ชัดเจนว่าขอให้ศาล
        มีคำสั่งอย่างไร]

                        ควรมิควรแล้วแต่จะโปรด
                        ลงชื่อ ......................... ผู้ร้อง/ทนาย

คำร้องฉบับนี้ ข้าพเจ้า [ชื่อทนาย] เป็นผู้เรียงและพิมพ์
                        ลงชื่อ ......................... ผู้เรียง/พิมพ์
```

หมายเหตุ: หัวกระดาษและช่องคดีหมายเลขเป็นไปตามแบบพิมพ์ของศาล หากเป็นคำร้องเข้าสำนวนคดีเดิม
ให้ระบุเลขคดีเดิม

## 5. แม่แบบคำแถลง

```
เรื่อง  [เช่น คำแถลงขอให้ปิดหมาย / คำแถลงประกอบคำร้อง]

        ข้าพเจ้า [ชื่อผู้ยื่น] ขอประทานกราบเรียนต่อศาลที่เคารพว่า
        [แจ้งข้อเท็จจริง/แสดงข้อมูลต่อศาล เช่น การส่งหมายไม่อาจส่งได้
        ตามภูมิลำเนา ขอแถลงข้อเท็จจริงเพิ่มเติม]

        จึงเรียนมาเพื่อโปรดทราบ [และดำเนินการตามที่เห็นสมควร]

                        ควรมิควรแล้วแต่จะโปรด
                        ลงชื่อ ......................... ผู้แถลง/ทนาย
```

## 6. หลักการเขียนเหตุผลในคำร้องที่ดี

- เปิดด้วย **ข้อเท็จจริง** ที่ทำให้ต้องยื่นคำร้อง สั้น ตรงประเด็น
- ตามด้วย **เหตุผลทางกฎหมาย** ว่าทำไมศาลควรมีคำสั่งตามที่ขอ
- ระบุ **คำขอ** ให้ชัดว่าขอให้ศาลสั่งอะไร — คำขอกำกวมทำให้ศาลสั่งให้ไม่ได้
- หากคำร้องกระทบสิทธิคู่ความอีกฝ่าย ให้เผื่อว่าศาลอาจให้โอกาสอีกฝ่ายคัดค้าน
- ทำเครื่องหมาย [....] ทุกจุดที่ผู้ใช้ต้องเติมข้อมูลจริง (วันที่ เลขคดี ชื่อบุคคล)
- ไม่ยื่นคำร้องที่รู้ว่าไม่มีมูลเพียงเพื่อประวิงคดี
