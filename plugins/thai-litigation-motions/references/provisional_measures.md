# provisional_measures.md — วิธีการชั่วคราวก่อนพิพากษาและคำขอในเหตุฉุกเฉิน

คลังคำร้องขอให้ศาลกำหนดวิธีการชั่วคราวเพื่อคุ้มครองสิทธิของคู่ความระหว่างที่คดียังไม่ถึงที่สุด

> ⚠️ เลขมาตราเป็นแนวอ้างอิงตาม ป.วิ.พ. (และวิธีพิจารณาเฉพาะกรณีคดีพิเศษ) ให้ยืนยันกับ
> ตัวบทฉบับปัจจุบันก่อนยื่น

---

## สารบัญ
1. ภาพรวมและประเภทของวิธีการชั่วคราว
2. คำร้องขอวิธีการชั่วคราวก่อนพิพากษา (ฝ่ายโจทก์)
3. คำขอในเหตุฉุกเฉิน
4. คำขอคุ้มครองประโยชน์ระหว่างพิจารณา
5. คำขอทุเลาการบังคับ (ชั้นอุทธรณ์/ฎีกา)

---

## 1. ภาพรวมและประเภทของวิธีการชั่วคราว

วิธีการชั่วคราวคือมาตรการที่ศาลกำหนดเพื่อ **รักษาสภาพหรือคุ้มครองสิทธิ** ระหว่างพิจารณา
มิให้คำพิพากษาที่จะได้ในภายหลังไร้ผล แบ่งคร่าว ๆ:
- **วิธีการที่โจทก์ขอเพื่อคุ้มครองก่อนพิพากษา** (หลักตาม ป.วิ.พ. ม.254) — เช่น ยึดหรืออายัด
  ทรัพย์สินของจำเลย ห้ามจำเลยจำหน่ายจ่ายโอนทรัพย์ที่พิพาท ห้ามชั่วคราวมิให้จำเลยกระทำการ
  อันก่อความเสียหาย และในบางกรณีถึงขั้นกักตัวจำเลย
- **คำขอในเหตุฉุกเฉิน** (หลักตาม ม.266–267) — ขอให้ศาลพิจารณาและสั่งโดยเร่งด่วน
- **คำขอคุ้มครองประโยชน์ของคู่ความระหว่างพิจารณา** (หลักตาม ม.264)

## 2. คำร้องขอวิธีการชั่วคราวก่อนพิพากษา (ฝ่ายโจทก์)

**เหตุที่ต้องบรรยายให้ครบ:**
1. มูลคดีและคำขอตามคำฟ้อง (คดีมีมูลที่จะชนะ)
2. เหตุที่แสดงว่า **หากไม่มีวิธีการชั่วคราว คำพิพากษาที่จะได้จะไร้ผลหรือบังคับได้ยาก** เช่น
   จำเลยกำลังจะโอน/ยักย้าย/จำหน่ายทรัพย์เพื่อหลีกเลี่ยงการบังคับคดี หรือทรัพย์ที่พิพาท
   เสี่ยงสูญหาย/เสื่อมค่า
3. ทรัพย์หรือการกระทำที่ขอให้ศาลกำหนดวิธีการ
**คำขอ:** ระบุวิธีการที่ขอให้ชัด เช่น ขอให้ยึด/อายัดทรัพย์สินรายการใด หรือห้ามจำเลยจำหน่าย
จ่ายโอนทรัพย์ใด
**ข้อควรระวัง:** ศาลอาจ **ไต่สวน** ก่อนมีคำสั่ง และอาจกำหนดให้ผู้ขอ **วางเงินหรือหา
ประกัน** เพื่อชดใช้ความเสียหายแก่ฝ่ายที่ถูกใช้วิธีการ หากภายหลังปรากฏว่าการขอนั้นไม่มีมูล
ผู้ขออาจต้องรับผิดในความเสียหาย — แจ้งความเสี่ยงนี้แก่ผู้ใช้

## 3. คำขอในเหตุฉุกเฉิน

**ใช้เมื่อ:** มีเหตุฉุกเฉินที่ต้องให้ศาลมีคำสั่งกำหนดวิธีการชั่วคราว **โดยทันที** เพราะหาก
รอตามขั้นตอนปกติจะเกิดความเสียหายที่แก้ไขไม่ได้
**เหตุที่ต้องบรรยาย:** นอกจากเหตุของวิธีการชั่วคราวตามข้อ 2 แล้ว ต้องบรรยาย **ความฉุกเฉิน**
ให้ชัด — เหตุการณ์ที่กำลังจะเกิดและความเสียหายที่จะตามมาหากไม่สั่งทันที
**ข้อควรระวัง:** เป็นกระบวนการเร่งด่วนที่ศาลพิจารณาเป็นพิเศษ การอ้างเหตุฉุกเฉินที่ไม่จริง
กระทบความน่าเชื่อถือและความรับผิดของผู้ขอ

## 4. คำขอคุ้มครองประโยชน์ระหว่างพิจารณา

**ใช้เมื่อ:** คู่ความฝ่ายใดฝ่ายหนึ่งประสงค์ให้ศาลมีคำสั่งเพื่อคุ้มครองประโยชน์ของตนใน
ระหว่างพิจารณา หรือเพื่อบังคับตามคำพิพากษา เช่น ขอให้นำเงินหรือทรัพย์ที่พิพาทมาวางต่อศาล
หรือให้อยู่ในความรักษาของบุคคลภายนอก
**เหตุที่ต้องบรรยาย:** ประโยชน์ที่ต้องคุ้มครอง และเหตุที่หากไม่มีคำสั่งจะเสียหาย

## 5. คำขอทุเลาการบังคับ (ชั้นอุทธรณ์/ฎีกา)

**ใช้เมื่อ:** คู่ความที่แพ้คดีและยื่นอุทธรณ์/ฎีกา ประสงค์ขอให้ **ทุเลาการบังคับคดีไว้ก่อน**
ระหว่างที่คดียังไม่ถึงที่สุด เพื่อมิให้มีการบังคับคดีไปก่อน
**เหตุที่ต้องบรรยาย:** การยื่นอุทธรณ์/ฎีกาและประเด็นที่คัดค้าน เหตุที่หากบังคับคดีไปก่อน
จะเกิดความเสียหายที่เยียวยายาก
**ข้อควรระวัง:** ศาลอาจกำหนดให้ผู้ขอ **วางเงินหรือหาประกัน** เป็นเงื่อนไขของการทุเลา —
ดูเรื่องการบังคับคดีประกอบใน `enforcement.md`

## Checklist วิธีการชั่วคราว
- [ ] บรรยายว่าคดีมีมูล และเหตุที่คำพิพากษาจะไร้ผลหากไม่มีวิธีการชั่วคราว
- [ ] ระบุทรัพย์/การกระทำที่ขอให้ศาลกำหนดวิธีการให้เฉพาะเจาะจง
- [ ] กรณีอ้างเหตุฉุกเฉิน — บรรยายความฉุกเฉินให้ชัดและเป็นจริง
- [ ] แจ้งผู้ใช้เรื่องการที่ศาลอาจให้วางเงิน/หาประกัน และความรับผิดหากการขอไม่มีมูล
- [ ] เลือกฐาน (วิธีการชั่วคราวปกติ / เหตุฉุกเฉิน / คุ้มครองประโยชน์ / ทุเลาการบังคับ) ให้ตรง
