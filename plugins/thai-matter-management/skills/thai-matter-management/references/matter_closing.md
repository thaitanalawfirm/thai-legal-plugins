# matter_closing.md — การปิดสำนวนและการเก็บรักษาเอกสาร

อ่านไฟล์นี้เมื่อต้องปิดสำนวนที่งานเสร็จแล้ว — การปิดที่ไม่เป็นระบบทำให้เอกสารสูญหาย เกิด
ข้อพิพาทเรื่องเอกสาร และเสี่ยงเรื่องความลับ/PDPA

---

## สารบัญ
1. เงื่อนไขก่อนปิดสำนวน
2. การจัดการเอกสารเมื่อปิด
3. การเก็บรักษาและการทำลายตามกำหนด
4. การบันทึกปิดสำนวนและบทเรียน
5. แม่แบบ checklist ปิดสำนวนและบันทึกปิด

---

## 1. เงื่อนไขก่อนปิดสำนวน

ตรวจก่อนปิดว่า:
- งานในขอบเขตเสร็จสิ้นแล้ว (หรือยุติด้วยเหตุที่ชัดเจน)
- **ไม่มีกำหนดเวลาที่ยังค้างอยู่** — ตรวจปฏิทินสำนวนว่าไม่มีอุทธรณ์/ฎีกา/บังคับคดี/งานต่อ
  เนื่องที่ยังเปิดสิทธิอยู่ (จุดที่พลาดบ่อย — ปิดสำนวนทั้งที่ยังมีสิทธิอุทธรณ์)
- ค่าวิชาชีพและค่าใช้จ่ายได้สะสางแล้ว หรือมีแนวทางจัดการ
- ได้แจ้งลูกความเรื่องการปิดและผลของเรื่อง

## 2. การจัดการเอกสารเมื่อปิด

- **ส่งคืนเอกสารต้นฉบับของลูกความ** ที่ลูกความควรได้คืน และบันทึกการส่งคืน
- จัดเอกสารในสำนวนให้ครบตามโครงแฟ้มก่อนจัดเก็บ
- ระบุว่าเอกสารใดเก็บไว้ (สำเนา/บันทึก) เอกสารใดส่งคืน
- ส่งมอบผลงาน/เอกสารสรุปที่ลูกความควรมีไว้ใช้ต่อ (เช่น คำพิพากษา สัญญาฉบับสมบูรณ์)

## 3. การเก็บรักษาและการทำลายตามกำหนด

- เก็บรักษาสำนวนตาม **ระยะเวลาที่เหมาะสม** ตามลักษณะเรื่องและกรอบที่เกี่ยวข้อง (เช่น เผื่อ
  การดำเนินการต่อเนื่อง การตรวจสอบ หรือข้อกำหนดทางวิชาชีพ/กฎหมาย)
- จัดเก็บอย่างปลอดภัย จำกัดการเข้าถึง — หน้าที่รักษาความลับยังอยู่แม้ปิดเรื่องแล้ว
- การจัดเก็บและทำลายข้อมูลส่วนบุคคลต้องสอดคล้อง **PDPA** (เก็บเท่าที่จำเป็นและมีฐาน ทำลาย
  เมื่อพ้นความจำเป็นอย่างปลอดภัย)
- บันทึกกำหนดการทบทวน/ทำลายเอกสารไว้ในระบบ
> ระยะเวลาเก็บรักษาเฉพาะเรื่องให้ตรวจกับกรอบที่ใช้บังคับ — ห้ามกำหนดตัวเลขลอย ๆ โดยไม่ตรวจ

## 4. การบันทึกปิดสำนวนและบทเรียน

- บันทึก **ผลของเรื่อง** และวันที่ปิด
- บันทึก **บทเรียน** ที่เป็นประโยชน์ต่อสำนวนอื่น (สิ่งที่ได้ผล/ควรปรับปรุง)
- อัปเดตสถานะในฐานข้อมูลเป็น "ปิดแล้ว" (ยังคงค้นเจอสำหรับการตรวจ conflict ในอนาคต)

## 5. แม่แบบ checklist ปิดสำนวนและบันทึกปิด

```
Checklist ปิดสำนวน — [รหัสสำนวน] [ชื่อเรื่อง]

[ ] งานในขอบเขตเสร็จสิ้น/ยุติด้วยเหตุชัดเจน
[ ] ตรวจแล้วไม่มีกำหนดเวลาค้าง (อุทธรณ์/ฎีกา/บังคับคดี/งานต่อเนื่อง)
[ ] ค่าวิชาชีพ/ค่าใช้จ่ายสะสางแล้วหรือมีแนวทางจัดการ
[ ] แจ้งลูกความเรื่องการปิดและผลของเรื่อง
[ ] ส่งคืนเอกสารต้นฉบับของลูกความ + บันทึกการส่งคืน
[ ] จัดเอกสารในสำนวนครบและจัดเก็บอย่างปลอดภัย
[ ] กำหนดระยะเวลาเก็บรักษาและการทบทวน/ทำลายตาม PDPA
[ ] บันทึกผลของเรื่องและบทเรียน
[ ] อัปเดตสถานะฐานข้อมูลเป็น "ปิดแล้ว"

บันทึกปิดสำนวน
- ผลของเรื่อง: [....]
- วันที่ปิด: [....]
- เอกสารที่ส่งคืน: [....]   เอกสารที่เก็บรักษา: [....]
- กำหนดทบทวน/ทำลายเอกสาร: [....]
- บทเรียน: [....]
- ผู้รับผิดชอบ: [....]
```

---

## หลักการ
- อย่าปิดสำนวนทั้งที่ยังมีกำหนดเวลา/สิทธิค้างอยู่
- ส่งคืนเอกสารลูกความและบันทึกให้ครบ
- เก็บรักษา/ทำลายตามกำหนดและสอดคล้อง PDPA — ความลับยังอยู่แม้ปิดเรื่อง
- ปิดท้ายด้วย "ข้อสังเกตจากทนาย" ตามมาตรฐานของสกิลนี้
