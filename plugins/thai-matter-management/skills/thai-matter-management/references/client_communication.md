# client_communication.md — การสื่อสารและรายงานลูกความ

อ่านไฟล์นี้เมื่อต้องวางรอบการสื่อสารหรือร่างรายงานความคืบหน้าต่อลูกความ

---

## สารบัญ
1. ทำไมการสื่อสารจึงสำคัญ
2. รอบและช่องทางการสื่อสาร
3. สิ่งที่ควรรายงาน
4. แม่แบบรายงานความคืบหน้า

---

## 1. ทำไมการสื่อสารจึงสำคัญ

- **การไม่สื่อสาร/ไม่อัปเดตเป็นสาเหตุข้อร้องเรียนอันดับต้น ๆ** ของลูกความต่อทนาย แม้งาน
  จะเดินอยู่ก็ตาม
- ลูกความที่ได้รับการอัปเดตสม่ำเสมอจะไว้วางใจและร่วมมือดีกว่า
- การสื่อสารที่ดีช่วยให้ลูกความตัดสินใจในเรื่องที่เป็นสิทธิของตน (เช่น การยอมความ) ได้ทันเวลา

## 2. รอบและช่องทางการสื่อสาร

- กำหนด **รอบรายงาน** ที่ชัด (เช่น ทุกครั้งที่มีความคืบหน้าสำคัญ และ/หรือตามรอบเวลา)
- รายงานทันทีเมื่อมี **เหตุการณ์สำคัญ** — คำสั่งศาล วันนัด ผลการเจรจา ข้อเสนอของอีกฝ่าย
- ระบุช่องทางที่ตกลงกับลูกความ และบันทึกการสื่อสารทุกครั้งลงสำนวน
- รักษาความลับในการสื่อสาร — ระวังการส่งข้อมูลผิดคนหรือช่องทางที่ไม่ปลอดภัย (PDPA)

## 3. สิ่งที่ควรรายงาน

- ความคืบหน้าตั้งแต่รายงานครั้งก่อน
- เหตุการณ์/คำสั่งสำคัญและความหมายต่อคดี/งาน
- ขั้นตอนถัดไปและกำหนดเวลาที่เกี่ยวข้อง
- สิ่งที่ต้องการจากลูกความ (ข้อมูล เอกสาร การตัดสินใจ)
- ประเด็นค่าใช้จ่าย/ค่าวิชาชีพ หากเกี่ยวข้อง
- **ไม่รับปากผล** — รายงานตามความเป็นจริง รวมถึงความเสี่ยงและพัฒนาการที่ไม่เป็นผลดี

## 4. แม่แบบรายงานความคืบหน้า

```
รายงานความคืบหน้า — [รหัสสำนวน] [ชื่อเรื่อง]
เรียน [ลูกความ]    วันที่ [....]

1. ความคืบหน้าล่าสุด
   [สรุปสิ่งที่เกิดขึ้นตั้งแต่รายงานครั้งก่อน]

2. เหตุการณ์/คำสั่งสำคัญ
   [ระบุ และความหมายต่อเรื่อง]

3. ขั้นตอนถัดไปและกำหนดเวลา
   [สิ่งที่จะทำต่อ และกำหนดที่เกี่ยวข้อง]

4. สิ่งที่ต้องการจากท่าน
   [ข้อมูล/เอกสาร/การตัดสินใจ — พร้อมกำหนดเวลาถ้ามี]

5. ค่าใช้จ่าย/ค่าวิชาชีพ (ถ้ามี)
   [สถานะ]

หากมีข้อสงสัย โปรดติดต่อ [ผู้รับผิดชอบ]
```

---

## หลักการ
- สื่อสารสม่ำเสมอ ทันเหตุการณ์ และบันทึกทุกครั้ง
- รายงานตามจริง ไม่รับปากผล
- ระบุสิ่งที่ต้องการจากลูกความให้ชัดพร้อมกำหนดเวลา
- รักษาความลับและความปลอดภัยของช่องทางสื่อสาร
- ปิดท้ายงานด้วย "ข้อสังเกตจากทนาย" ตามมาตรฐานของสกิลนี้
