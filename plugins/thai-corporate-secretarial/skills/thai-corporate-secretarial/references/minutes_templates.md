# minutes_templates.md — แม่แบบมติและรายงานการประชุม

ใช้แม่แบบเหล่านี้ร่างเอกสารการประชุม ปรับตามประเภทบริษัทและเรื่อง

> ทำเครื่องหมาย [....] ทุกจุดที่ต้องเติม · ยืนยันองค์ประชุม/เสียงจากตัวบทระดับ A ·
> ทุกฉบับเป็นร่างให้ทนายผู้รับผิดชอบตรวจรับรอง · รายงานต้องตรงกับสิ่งที่เกิดขึ้นจริง

---

## 1. แม่แบบหนังสือเชิญประชุมผู้ถือหุ้น

```
หนังสือเชิญประชุม[สามัญ/วิสามัญ]ผู้ถือหุ้น ครั้งที่ [....]
บริษัท [....] จำกัด

ด้วยที่ประชุมคณะกรรมการมีมติให้เรียกประชุมผู้ถือหุ้น ในวันที่ [....] เวลา [....]
ณ [สถานที่] เพื่อพิจารณาเรื่องตามระเบียบวาระดังนี้

วาระที่ 1 [....]
วาระที่ 2 [....] (กรณีเป็นเรื่องที่ต้องใช้มติพิเศษ ให้ระบุชัด)
...

จึงเรียนเชิญผู้ถือหุ้นเข้าร่วมประชุมตามวันเวลาและสถานที่ดังกล่าว
(เอกสารประกอบ/หนังสือมอบฉันทะ ตามที่กำหนด)

                                ลงชื่อ ..................... กรรมการผู้มีอำนาจ
                                วันที่ [....]

* การบอกกล่าวต้องเป็นไปตามกำหนดเวลาและวิธีที่กฎหมาย/ข้อบังคับกำหนด
```

## 2. แม่แบบรายงานการประชุมผู้ถือหุ้น

```
รายงานการประชุม[สามัญ/วิสามัญ]ผู้ถือหุ้น ครั้งที่ [....]
บริษัท [....] จำกัด

ประชุมเมื่อวันที่ [....] เวลา [....] ณ [สถานที่]

ผู้ถือหุ้นเข้าประชุม: [จำนวนราย] ถือหุ้นรวม [จำนวน] หุ้น คิดเป็น [ร้อยละ] ของหุ้นที่จำหน่าย
ได้แล้วทั้งหมด — ครบองค์ประชุมตาม [กฎหมาย/ข้อบังคับ]

เริ่มประชุมเวลา [....] โดย [ประธาน] เป็นประธาน

วาระที่ 1 [เรื่อง]
   [สรุปการพิจารณา]
   มติ: ที่ประชุมมีมติ[อนุมัติ/...] ด้วยคะแนนเสียง [....] (ระบุประเภทมติ ธรรมดา/พิเศษ)

วาระที่ 2 [เรื่อง]
   ...

ปิดประชุมเวลา [....]

                                ลงชื่อ ..................... ประธานที่ประชุม
```

## 3. แม่แบบรายงานการประชุมคณะกรรมการ

```
รายงานการประชุมคณะกรรมการ ครั้งที่ [....]
บริษัท [....] จำกัด

ประชุมเมื่อวันที่ [....] เวลา [....] ณ [สถานที่]
กรรมการเข้าประชุม [จำนวน] คน จากทั้งหมด [จำนวน] คน — ครบองค์ประชุม

วาระที่ 1 [เรื่อง]
   มติ: [....]
...
ปิดประชุมเวลา [....]
                                ลงชื่อ ..................... ประธานกรรมการ
```

## 4. แม่แบบมติ (กรณีใช้รูปแบบมติเป็นเอกสารแยก)

```
มติที่ประชุม[ผู้ถือหุ้น/คณะกรรมการ] บริษัท [....] จำกัด
เรื่อง [....]   วันที่ [....]

ที่ประชุมพิจารณาแล้วมีมติ [อนุมัติ/มอบหมาย/...] ดังนี้
   [ข้อความมติ]
ด้วยคะแนนเสียง [....] (มติ[ธรรมดา/พิเศษ])
```

---

## ข้อควรจำ
- ระบุวาระที่ต้องใช้มติพิเศษให้ชัดในหนังสือเชิญประชุม
- บันทึกองค์ประชุมและคะแนนเสียงให้ตรงความจริง
- ยืนยันองค์ประชุม/เสียงข้างมากจากตัวบทระดับ A (ป.พ.พ./พ.ร.บ.มหาชน) และข้อบังคับบริษัท
- ห้ามจัดทำรายงานย้อนหลังให้เป็นเท็จ
- ปิดท้ายด้วย "ข้อสังเกตจากทนาย" และระบุว่าเป็นร่างให้ทนายผู้รับผิดชอบรับรอง
