# corporate_changes.md — การเปลี่ยนแปลงที่ต้องจดทะเบียน

อ่านไฟล์นี้เมื่อต้องดำเนินการเปลี่ยนแปลงทะเบียนบริษัท

> ⚠️ แต่ละเรื่องใช้ "มติ" และ "กำหนดเวลายื่น" ต่างกัน ตรวจจากตัวบทระดับ A (ป.พ.พ./พ.ร.บ.
> มหาชน) และระเบียบ DBD ฉบับปัจจุบัน — ห้ามประดิษฐ์เสียงข้างมากหรือกำหนดเวลา

---

## สารบัญ
1. ภาพรวม: การเปลี่ยนแปลงต้องมีมติและจดทะเบียน
2. การเปลี่ยนแปลงที่พบบ่อยและข้อพิจารณา
3. ลำดับการดำเนินการทั่วไป
4. กำหนดเวลายื่นจดทะเบียน

---

## 1. ภาพรวม: การเปลี่ยนแปลงต้องมีมติและจดทะเบียน

การเปลี่ยนแปลงสำคัญของบริษัทโดยทั่วไปต้อง (1) มีมติของที่ประชุมที่ถูกต้อง (มติธรรมดาหรือมติ
พิเศษแล้วแต่เรื่อง) และ (2) ยื่นจดทะเบียนการเปลี่ยนแปลงต่อ DBD ภายในกำหนด — ตรวจว่าแต่ละเรื่อง
ใช้มติประเภทใดและมีกำหนดเวลายื่นเท่าใดจากตัวบท

## 2. การเปลี่ยนแปลงที่พบบ่อยและข้อพิจารณา

| เรื่อง | ข้อพิจารณา (ตรวจตัวบทเพื่อยืนยันมติ/ขั้นตอน) |
|--------|-----------------------------------------------|
| เปลี่ยนกรรมการ / อำนาจกรรมการ | โดยหลักใช้มติที่ประชุม แล้วจดทะเบียนเปลี่ยนแปลง |
| เพิ่มทุน / ลดทุน | โดยหลักต้องใช้ **มติพิเศษ** และมีขั้นตอน/การคุ้มครองเจ้าหนี้ (ลดทุน) ตามที่กฎหมายกำหนด |
| แก้ไขหนังสือบริคณห์สนธิ / ข้อบังคับ | โดยหลักต้องใช้ **มติพิเศษ** |
| ย้ายที่ตั้งสำนักงาน | จดทะเบียนเปลี่ยนแปลง (ข้ามจังหวัดอาจมีขั้นตอนเพิ่ม) |
| เปลี่ยน/เพิ่มวัตถุประสงค์ | โดยหลักต้องแก้หนังสือบริคณห์สนธิ (มติพิเศษ) |
| เปลี่ยนชื่อบริษัท / ตราประทับ | จองชื่อใหม่ แก้หนังสือบริคณห์สนธิ และจดทะเบียน |
| เปลี่ยนแปลงผู้ถือหุ้น | ปรับบัญชีรายชื่อผู้ถือหุ้นและนำส่งตามที่กฎหมายกำหนด |

> ตารางนี้เป็นแนวทาง — ประเภทมติและขั้นตอนจริงต้องยืนยันกับตัวบทระดับ A และอาจต่างกันระหว่าง
> บริษัทจำกัดกับมหาชน

## 3. ลำดับการดำเนินการทั่วไป

1. ตรวจว่าเรื่องนั้นใช้มติประเภทใด และองค์ประชุม/เสียงเท่าใด (ดู `meetings_resolutions.md`)
2. ออกหนังสือเชิญประชุมให้ถูกต้องตามกำหนดเวลาและวิธี
3. จัดประชุมและลงมติ จัดทำรายงานการประชุม (ดู `minutes_templates.md`)
4. จัดเตรียมคำขอจดทะเบียนและเอกสารประกอบ
5. ยื่นจดทะเบียนต่อ DBD ภายในกำหนด และปรับปรุงเอกสารบริษัทให้ตรง

## 4. กำหนดเวลายื่นจดทะเบียน

- การเปลี่ยนแปลงหลายเรื่องมี **กำหนดเวลายื่นจดทะเบียนนับแต่วันมีมติ/วันที่เปลี่ยนแปลง** —
  ยื่นช้าอาจมีโทษปรับ
- ตรวจกำหนดเวลาของแต่ละเรื่องจากตัวบท/ระเบียบ DBD และส่งไปคำนวณที่
  `thai-litigation-deadlines` หากต้องนับวัน
- ตั้งเตือนล่วงหน้าและเผื่อเวลา

---

## หลักการ
- ทุกการเปลี่ยนแปลงสำคัญ = มติที่ถูกต้อง + จดทะเบียนภายในกำหนด
- ยืนยันประเภทมติและกำหนดเวลาจากตัวบทระดับ A ไม่เดา
- ปรับเอกสารบริษัทให้ตรงกับที่จดทะเบียนหลังเปลี่ยนแปลง
