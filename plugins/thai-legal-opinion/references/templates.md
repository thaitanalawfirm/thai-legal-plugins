# templates.md — แม่แบบหนังสือความเห็นและบันทึกความเห็น

ใช้แม่แบบเหล่านี้เป็นโครง แล้วปรับตามประเภทความเห็น (ดู `opinion_types.md`)

> ทำเครื่องหมาย [....] ทุกจุดที่ผู้ใช้ต้องเติมข้อมูลจริง

---

## 1. แม่แบบหนังสือความเห็นทางกฎหมาย (Opinion Letter)

```
                                            วันที่ [....]

เรียน  [ชื่อลูกความ/ผู้รับ]
เรื่อง  ความเห็นทางกฎหมายเกี่ยวกับ [ระบุเรื่อง]

ตามที่ท่านได้ขอให้ข้าพเจ้าให้ความเห็นทางกฎหมายเกี่ยวกับ [ประเด็น] นั้น
ข้าพเจ้าขอเรียนความเห็นดังต่อไปนี้

1. ขอบเขตและวัตถุประสงค์
   ความเห็นนี้จัดทำขึ้นเพื่อ [วัตถุประสงค์] โดยพิจารณาเฉพาะประเด็นตามข้อ 4
   ภายใต้กฎหมายไทยที่ใช้บังคับ ณ วันที่ออกความเห็นนี้

2. เอกสารและข้อเท็จจริงที่พิจารณา
   ข้าพเจ้าได้พิจารณาจากเอกสารและข้อเท็จจริงดังนี้
   2.1 [เอกสาร/ข้อเท็จจริง]
   2.2 [....]

3. สมมติฐาน
   ในการให้ความเห็นนี้ ข้าพเจ้าตั้งอยู่บนสมมติฐานว่า
   3.1 [เช่น เอกสารที่ได้รับเป็นของแท้และมีผลสมบูรณ์]
   3.2 [....]

4. ประเด็นที่พิจารณา
   4.1 [ประเด็นที่ 1]
   4.2 [ประเด็นที่ 2]

5. การวิเคราะห์
   ประเด็นที่ 4.1: [ยกหลักกฎหมาย/มาตราจากคลังระดับ A → ปรับใช้กับข้อเท็จจริง → เหตุผล]
   ประเด็นที่ 4.2: [เช่นเดียวกัน]

6. ความเห็น
   6.1 ในประเด็นที่ 4.1 ข้าพเจ้าเห็นว่า [ข้อสรุป] โดย [ระดับความเชื่อมั่น]
   6.2 ในประเด็นที่ 4.2 ข้าพเจ้าเห็นว่า [ข้อสรุป] [ระดับความเชื่อมั่น]

7. ข้อสงวน
   7.1 ความเห็นนี้อยู่บนฐานข้อเท็จจริง เอกสาร และสมมติฐานข้างต้น
   7.2 ความเห็นนี้อิงกฎหมายไทย ณ วันที่ออกความเห็น และอาจเปลี่ยนหากกฎหมายหรือข้อเท็จจริง
       เปลี่ยนแปลง
   7.3 ความเห็นนี้จำกัดเฉพาะประเด็นที่ระบุ มิใช่การรับรองข้อเท็จจริงหรือรับประกันผล
   7.4 ความเห็นนี้จัดทำเพื่อ [ผู้รับ] เพื่อวัตถุประสงค์ที่ระบุเท่านั้น

                                ขอแสดงความนับถือ
                                [ชื่อผู้ให้ความเห็น]
                                (ร่างเพื่อให้ทนายผู้รับผิดชอบตรวจและรับรองก่อนออก)
```

## 2. แม่แบบบันทึกความเห็นภายใน (Legal Memo)

```
บันทึกความเห็นทางกฎหมาย

ถึง      : [....]
จาก      : [....]
วันที่    : [....]
เรื่อง    : [ประเด็น]

1. คำถาม/ประเด็น
   [ระบุประเด็นกฎหมายที่พิจารณา]

2. คำตอบโดยสรุป (Bottom Line)
   [สรุปคำตอบสั้น ๆ พร้อมระดับความเชื่อมั่น — ให้ผู้บริหารอ่านแล้วเข้าใจทันที]

3. ข้อเท็จจริงและสมมติฐาน
   [สรุปข้อเท็จจริงที่ใช้ และสมมติฐาน]

4. การวิเคราะห์
   [ยกหลักกฎหมายจากคลังระดับ A → ปรับใช้ → พิจารณาทั้งสองด้าน]

5. ความเสี่ยงและข้อเสนอแนะ
   [ความเสี่ยงที่เห็น + แนวทางลดความเสี่ยง/ทางเลือกเชิงปฏิบัติ]

6. ข้อจำกัดของบันทึกนี้
   [ขอบเขต ข้อมูลที่ยังขาด และสิ่งที่ต้องตรวจสอบเพิ่ม]
```

## 3. แม่แบบตอบข้อหารือสั้น (Quick Advisory)

```
เรื่อง: [ประเด็น]

คำตอบโดยสรุป: [ตอบตรงประเด็น + ระดับความเชื่อมั่น]

เหตุผลโดยย่อ: [หลักกฎหมายที่ใช้ (อ้างมาตราจากคลังระดับ A) + การปรับใช้สั้น ๆ]

ข้อควรระวัง: [ความเสี่ยง/เงื่อนไข/ข้อมูลที่ยังต้องยืนยัน]

หมายเหตุ: เป็นความเห็นเบื้องต้นบนข้อมูลที่ได้รับ หากต้องใช้ประกอบการตัดสินใจสำคัญ
ควรขอความเห็นเต็มรูปแบบ
```

---

## ข้อควรจำเมื่อใช้แม่แบบ
- เลือกแม่แบบให้ตรงกับการใช้งานของลูกความ (ทางการ/ภายใน/สั้น)
- อย่าตัดส่วน "สมมติฐาน" และ "ข้อสงวน" ออก แม้ในเวอร์ชันสั้น (ย่อได้แต่ต้องมี)
- อ้างมาตราจากคลังระดับ A และตรวจฎีกาก่อนใส่
- ปิดท้ายด้วย "ข้อสังเกตจากทนาย" ตามมาตรฐานของสกิลนี้
