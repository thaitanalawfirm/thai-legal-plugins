# procedure_core.md — หลักวิธีพิจารณาร่วมและแม่แบบคำคู่ความ

อ่านไฟล์นี้ก่อนร่างคำคู่ความทุกประเภท เพราะเป็นโครงสร้างและกรอบกระบวนการที่ใช้ร่วมกัน

## สารบัญ
1. การเลือกศาลและเขตอำนาจ
2. ทุนทรัพย์และค่าขึ้นศาล
3. ระยะเวลาสำคัญ
4. แม่แบบคำฟ้องแพ่ง
5. แม่แบบคำขอท้ายฟ้อง
6. แม่แบบคำให้การ
7. แม่แบบฟ้องแย้ง
8. หลักการบรรยายฟ้องที่ดี

---

## 1. การเลือกศาลและเขตอำนาจ

ตรวจสองชั้นเสมอ:
- **อำนาจศาล (ศาลใดมีอำนาจพิจารณาประเภทคดีนี้):** ศาลแขวง / ศาลจังหวัด / ศาลแพ่ง / ศาลแรงงาน / ศาลเยาวชนและครอบครัว / ศาลทรัพย์สินทางปัญญาฯ
- **เขตอำนาจตามท้องที่:** โดยหลักยื่นต่อศาลที่ **จำเลยมีภูมิลำเนา** หรือศาลที่ **มูลคดีเกิดขึ้น** คดีเกี่ยวด้วยอสังหาริมทรัพย์ยื่นต่อศาลที่ทรัพย์นั้นตั้งอยู่

แนวแบ่งศาลแขวง/ศาลจังหวัด (คดีแพ่ง): คดีที่ทุนทรัพย์ไม่เกิน 300,000 บาท และคดีมโนสาเร่ อยู่ในอำนาจศาลแขวง คดีเกินกว่านั้นอยู่ในอำนาจศาลจังหวัด/ศาลแพ่ง — ระบุเหตุผลการเลือกศาลไว้ในผังประเด็นเสมอ และตรวจสอบเพดานปัจจุบันก่อนยืนยัน

## 2. ทุนทรัพย์และค่าขึ้นศาล

- **ทุนทรัพย์** = จำนวนเงินหรือมูลค่าทรัพย์ที่พิพาท รวมดอกเบี้ยที่ถึงกำหนดก่อนฟ้อง (ดอกเบี้ยอนาคตไม่นับเป็นทุนทรัพย์)
- **ค่าขึ้นศาล** คดีมีทุนทรัพย์โดยทั่วไปคิดเป็นอัตราขั้นบันไดของทุนทรัพย์ และมีเพดาน — **ห้ามระบุตัวเลขตายตัว** ให้สั่งผู้ใช้ตรวจสอบตาราง 1 ท้าย ป.วิ.พ. ฉบับปัจจุบัน
- คดีไม่มีทุนทรัพย์ (เช่น ขอให้รื้อถอน ขอแสดงกรรมสิทธิ์) เสียค่าขึ้นศาลแบบคดีไม่มีทุนทรัพย์
- เตือนผู้ใช้เรื่องค่าส่งหมายและค่าใช้จ่ายในการดำเนินคดีแยกจากค่าขึ้นศาล

## 3. ระยะเวลาสำคัญ

- จำเลยยื่นคำให้การภายใน **15 วัน** นับแต่วันได้รับหมายเรียกและสำเนาคำฟ้อง (กรณีส่งในราชอาณาจักร)
- หากขาดนัดยื่นคำให้การ โจทก์อาจขอให้ศาลพิพากษาให้ตนชนะคดีโดยขาดนัด
- คดีแรงงานและคดีผู้บริโภคมีกระบวนการเร่งรัดและผ่อนปรนรูปแบบ ดูไฟล์เฉพาะคดี
- ตรวจอายุความของมูลคดีก่อนเสมอ (รายละเอียดในไฟล์เฉพาะคดี)

## 4. แม่แบบคำฟ้องแพ่ง

```
                                        คดีหมายเลขดำที่ ........./...........
                                        คดีหมายเลขแดงที่ ........./...........

                          ศาล[ชื่อศาล]

ความ[แพ่ง/อาญา]

[ชื่อ-นามสกุลโจทก์] อายุ .... ปี อยู่บ้านเลขที่ ....              โจทก์
        ระหว่าง
[ชื่อ-นามสกุลจำเลย] อายุ .... ปี อยู่บ้านเลขที่ ....              จำเลย

เรื่อง  [ระบุเรื่อง เช่น ผิดสัญญากู้ยืมเงิน / ละเมิด เรียกค่าเสียหาย]

จำนวนทุนทรัพย์ .................. บาท

        ข้อ 1. [บรรยายฐานะคู่ความและความเกี่ยวพัน เช่น โจทก์และจำเลย
        ได้ทำสัญญา.... เมื่อวันที่....]

        ข้อ 2. [บรรยายข้อเท็จจริงที่ก่อให้เกิดสิทธิ เรียงตามลำดับเวลา
        ให้ครบองค์ประกอบของข้อหา]

        ข้อ 3. [บรรยายการผิดนัด/การกระทำละเมิด และความเสียหายที่เกิดขึ้น
        พร้อมการบอกกล่าวทวงถาม ถ้ามี]

        ข้อ 4. [สรุปมูลหนี้/ค่าเสียหายทั้งหมด พร้อมดอกเบี้ย
        ระบุอัตราและวันเริ่มคิดดอกเบี้ย]

        โจทก์ไม่มีทางอื่นที่จะบังคับจำเลยได้ จึงต้องนำคดีมาฟ้องต่อศาล
        ขอบารมีศาลเป็นที่พึ่ง

                        ควรมิควรแล้วแต่จะโปรด
                        ลงชื่อ ......................... โจทก์/ทนายโจทก์

คำฟ้องฉบับนี้ ข้าพเจ้า [ชื่อทนาย] ทนายความโจทก์เป็นผู้เรียงและพิมพ์
                        ลงชื่อ ......................... ผู้เรียง/พิมพ์
```

หมายเหตุ: หัวกระดาษและช่องคดีหมายเลขเป็นไปตามแบบพิมพ์ของศาล ให้เว้นช่องที่ศาลกรอก

## 5. แม่แบบคำขอท้ายฟ้อง

```
        คำขอท้ายคำฟ้อง[แพ่ง]

        ขอศาลได้โปรดออกหมายเรียกตัวจำเลยมาพิจารณาพิพากษา และบังคับจำเลยดังนี้
        1. ให้จำเลยชำระเงินจำนวน ............ บาท แก่โจทก์
        2. ให้จำเลยชำระดอกเบี้ยอัตราร้อยละ .... ต่อปี ของต้นเงิน ........ บาท
           นับแต่วันที่ ........ เป็นต้นไปจนกว่าจะชำระเสร็จแก่โจทก์
        3. ให้จำเลยใช้ค่าฤชาธรรมเนียมและค่าทนายความแทนโจทก์
        4. [คำขออื่น เช่น ให้ขับไล่ ให้รื้อถอน ให้ส่งมอบทรัพย์]
```

หลักสำคัญ: คำขอท้ายฟ้องต้องสอดคล้องกับข้อเท็จจริงที่บรรยาย ศาลพิพากษาเกินคำขอไม่ได้ และทุกคำขอต้องบังคับคดีได้จริง

## 6. แม่แบบคำให้การ

```
        ข้อ 1. จำเลยขอให้การปฏิเสธฟ้องของโจทก์ทั้งสิ้น เว้นแต่ที่จะได้
        ให้การรับไว้โดยชัดแจ้งต่อไปนี้

        ข้อ 2. จำเลยรับว่า [ข้อเท็จจริงที่รับ เช่น เคยทำสัญญากับโจทก์จริง]

        ข้อ 3. จำเลยปฏิเสธว่า [ข้ออ้างของโจทก์ข้อใดที่ปฏิเสธ พร้อมเหตุแห่ง
        การปฏิเสธโดยชัดแจ้ง อ้างอิงข้อของคำฟ้องที่โต้แย้ง]

        ข้อ 4. [ยกข้อต่อสู้ เช่น คดีขาดอายุความ / ฟ้องเคลือบคลุม /
        โจทก์ไม่มีอำนาจฟ้อง / จำเลยชำระหนี้แล้ว]

        ด้วยเหตุดังกล่าว ขอศาลได้โปรดพิพากษายกฟ้องโจทก์ และให้โจทก์
        ใช้ค่าฤชาธรรมเนียมและค่าทนายความแทนจำเลย
```

ต้องตอบให้ครบทุกข้อของคำฟ้อง ข้อที่ไม่ปฏิเสธโดยชัดแจ้งอาจถือว่ารับ

## 7. แม่แบบฟ้องแย้ง

ฟ้องแย้งต้องรวมอยู่ในคำให้การฉบับเดียวกัน และเกี่ยวข้องกับฟ้องเดิมพอที่จะรวมพิจารณาได้:

```
        ฟ้องแย้ง

        ข้อ 5. นอกจากให้การปฏิเสธแล้ว จำเลยขอฟ้องแย้งโจทก์ว่า
        [บรรยายข้อเท็จจริงที่ก่อสิทธิของจำเลยต่อโจทก์]

        คำขอท้ายฟ้องแย้ง
        ขอศาลได้โปรดบังคับโจทก์ (จำเลยตามฟ้องแย้ง) ดังนี้
        1. [คำขอบังคับของจำเลย]
        2. ให้โจทก์ใช้ค่าฤชาธรรมเนียมแทนจำเลย
```

## 8. หลักการบรรยายฟ้องที่ดี

- บรรยายข้อเท็จจริง **เรียงตามลำดับเวลา** แยกเป็นข้อสั้น ๆ ข้อละประเด็น
- ทุก **องค์ประกอบของข้อหา** ต้องมีข้อเท็จจริงรองรับครบ ไม่งั้นเสี่ยงฟ้องเคลือบคลุม
- ระบุ **วัน เดือน ปี จำนวนเงิน ชื่อบุคคล** ให้ชัด อย่าใช้คำคลุมเครือ
- บรรยายเฉพาะ **ข้อเท็จจริง** ส่วนการปรับบทกฎหมายและการนำสืบเป็นเรื่องชั้นพิจารณา
- อย่าบรรยายข้อเท็จจริงที่เปิดช่องให้ฝ่ายตรงข้าม (เช่น ยอมรับว่ารู้เหตุมานานจนเข้าข่ายขาดอายุความ)
- ทำเครื่องหมาย [....] ทุกจุดที่ผู้ใช้ต้องเติมข้อมูลจริง
