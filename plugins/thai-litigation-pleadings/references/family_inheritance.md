# family_inheritance.md — คลังคดีครอบครัวและมรดก (ฉบับครอบคลุม)

คลังอ้างอิงสำหรับร่างคำฟ้องและคำร้องในคดีครอบครัวและคดีมรดก

> ⚠️ **คำเตือนเรื่องเลขมาตรา:** เลขมาตราในไฟล์นี้เป็นแนวอ้างอิงตามประมวลกฎหมายแพ่งและ
> พาณิชย์ บรรพ 5 (ครอบครัว) และบรรพ 6 (มรดก) บทบัญญัติเรื่องครอบครัวมีการแก้ไขสำคัญตาม
> **กฎหมายสมรสเท่าเทียม** ซึ่งใช้ถ้อยคำเป็นกลางทางเพศ ("ผู้หมั้น" "คู่สมรส" "บุคคล")
> ครอบคลุมคู่สมรสทุกเพศ **ให้ทนายผู้รับผิดชอบยืนยันถ้อยคำและเลขมาตราฉบับปัจจุบันก่อนยื่นเสมอ**

---

## สารบัญ

- **ส่วน 0 — หลักร่วมของคดีครอบครัวและมรดก**
- **ส่วน 1 — คดีครอบครัว** (1.1–1.9)
- **ส่วน 2 — คดีมรดก** (2.1–2.6)
- **ส่วน 3 — แม่แบบคำฟ้องและคำร้อง**
- **ส่วน 4 — Checklist คดีครอบครัวและมรดก**

---

# ส่วน 0 — หลักร่วมของคดีครอบครัวและมรดก

- คดีครอบครัวและคดีมรดกหลายประเภทพิจารณาใน**ศาลเยาวชนและครอบครัว** มีกระบวนการ **ไกล่เกลี่ย**
  และคำนึงถึง **ประโยชน์สูงสุดของบุตรผู้เยาว์** เป็นสำคัญ
- แยกบทบาทเอกสารให้ชัด: **"คำร้องขอ"** สำหรับคดีไม่มีข้อพิพาท (เช่น ตั้งผู้จัดการมรดก
  ตั้งผู้ปกครอง) — **"คำฟ้อง"** สำหรับคดีมีข้อพิพาท (เช่น ฟ้องหย่า ฟ้องแบ่งมรดก)
- คดีกลุ่มนี้ต้องแนบเอกสารทะเบียนเป็นพยานหลักฐานหลัก: ทะเบียนสมรส ทะเบียนการหย่า สูติบัตร
  มรณบัตร ทะเบียนบ้าน บัตรประจำตัวประชาชน โฉนดที่ดิน พินัยกรรม — ระบุให้ผู้ใช้จัดเตรียม
- ตรวจความสามารถของคู่ความ: ผู้เยาว์ต้องมีผู้แทนโดยชอบธรรม คนไร้/เสมือนไร้ความสามารถต้องมี
  ผู้อนุบาล/ผู้พิทักษ์
- ใช้ถ้อยคำที่เป็นกลางทางเพศตามกฎหมายปัจจุบัน เว้นแต่ข้อเท็จจริงของคดีระบุเป็นอย่างอื่น

---

# ส่วน 1 — คดีครอบครัว

## 1.1 ฟ้องหย่า

**ฐานกฎหมาย:** เหตุฟ้องหย่าตามหลักใน ป.พ.พ. ม.1516
**องค์ประกอบที่ต้องบรรยาย:** 1) คู่ความเป็นคู่สมรสโดยชอบด้วยกฎหมาย จดทะเบียนสมรสเมื่อใด
2) มีบุตรด้วยกันหรือไม่ ชื่อ อายุ 3) **เหตุหย่าตามกฎหมาย** ที่ยกขึ้นอ้าง พร้อมข้อเท็จจริง
รองรับครบ 4) คำขอเรื่องบุตร สินสมรส และค่าทดแทน/ค่าเลี้ยงชีพ (ถ้ามี)

**เหตุหย่าตามกฎหมายโดยสังเขป (ตรวจถ้อยคำและอนุมาตราฉบับปัจจุบัน):**
- อีกฝ่ายอุปการะเลี้ยงดูหรือยกย่องผู้อื่นฉันคู่สมรส มีความสัมพันธ์ทำนองชู้สาว หรือร่วม
  ประเวณีกับผู้อื่นเป็นอาจิณ
- ประพฤติชั่ว ทำให้อีกฝ่ายอับอายขายหน้าอย่างร้ายแรง ถูกเกลียดชัง หรือเสียหาย/เดือดร้อนเกินควร
- ทำร้าย ทรมานร่างกายหรือจิตใจ หรือหมิ่นประมาท/เหยียดหยามอีกฝ่ายหรือบุพการีของอีกฝ่ายอย่าง
  ร้ายแรง
- จงใจละทิ้งร้างอีกฝ่ายไปเกินกำหนดที่กฎหมายกำหนด
- สมัครใจแยกกันอยู่เพราะเหตุที่ไม่อาจอยู่ร่วมกันฉันคู่สมรสได้โดยปกติสุขตลอดมาเกินกำหนด
- ไม่ให้ความช่วยเหลืออุปการะเลี้ยงดูตามสมควร หรือทำการเป็นปฏิปักษ์ต่อการเป็นคู่สมรสกัน
  อย่างร้ายแรง
- วิกลจริตตลอดมาเกินกำหนด / เป็นโรคติดต่ออย่างร้ายแรง / มีสภาพแห่งกายไม่อาจร่วมประเวณีได้
  ตลอดกาล / ผิดทัณฑ์บนที่ทำเป็นหนังสือเรื่องประพฤติชั่ว
**จุดที่ทำให้แพ้:** บรรยายเหตุลอย ๆ ว่า "เข้ากันไม่ได้" โดยไม่ปรับให้เข้าเหตุหย่าตามกฎหมาย /
ฝ่ายที่ฟ้องเป็นผู้ก่อเหตุเอง / ข้อเท็จจริงไม่ถึงระดับ "ร้ายแรง" ตามที่กฎหมายกำหนด

## 1.2 อำนาจปกครองบุตร

**องค์ประกอบที่ต้องบรรยาย:** ความเป็นบิดามารดาและบุตร เหตุที่ขอให้บุตรอยู่ในอำนาจปกครองของ
ฝ่ายใด โดยแสดงว่าเป็นไป **เพื่อประโยชน์สูงสุดของบุตร** (ความพร้อมในการเลี้ยงดู ความผูกพัน
สภาพแวดล้อม)
**คำขอ:** ขอให้โจทก์เป็นผู้ใช้อำนาจปกครองแต่ผู้เดียว และอาจขอกำหนดการติดต่อกับบุตรของอีกฝ่าย

## 1.3 ค่าอุปการะเลี้ยงดู

**องค์ประกอบที่ต้องบรรยาย:** หน้าที่อุปการะเลี้ยงดู (บิดามารดาต่อบุตร / ระหว่างคู่สมรส)
ความจำเป็นของผู้มีสิทธิรับ และความสามารถของผู้มีหน้าที่จ่าย จำนวนที่ขอต่อเดือน
**ข้อสังเกต:** ค่าอุปการะเลี้ยงดูอาจขอแก้ไขเพิ่ม-ลดได้เมื่อพฤติการณ์เปลี่ยนแปลง — ระบุได้ใน
คำขอ / สิทธิได้ค่าอุปการะของบุตรเป็นไปจนบุตรบรรลุนิติภาวะ (เว้นแต่กรณีพิเศษ)

## 1.4 ค่าทดแทนและค่าเลี้ยงชีพจากการหย่า

**ค่าทดแทน:** กรณีเหตุหย่าเกิดจากความผิดของอีกฝ่าย (เช่น มีความสัมพันธ์กับผู้อื่น ประพฤติชั่ว)
ฝ่ายที่ต้องหย่าเพราะการกระทำนั้นอาจเรียกค่าทดแทนได้ และอาจเรียกค่าทดแทนจากผู้อื่นที่ล่วงเกิน
คู่สมรสของตนในทำนองชู้สาว
**ค่าเลี้ยงชีพ:** หากการหย่าทำให้ฝ่ายหนึ่งยากจนลงและฝ่ายนั้นมิได้เป็นฝ่ายผิด อาจขอค่าเลี้ยงชีพ
จากอีกฝ่ายได้ — บรรยายฐานะและความจำเป็น

## 1.5 แบ่งสินสมรส

**องค์ประกอบที่ต้องบรรยาย:** แยกให้ชัดระหว่าง **สินส่วนตัว** (ทรัพย์มีอยู่ก่อนสมรส ของใช้
ส่วนตัว ทรัพย์ได้มาระหว่างสมรสโดยการรับมรดกหรือการให้โดยเสน่หาเฉพาะตัว) กับ **สินสมรส**
(ทรัพย์ที่ได้มาระหว่างสมรสนอกจากนั้น) — ระบุรายการสินสมรสแต่ละรายการพร้อมมูลค่า
**คำขอ:** โดยหลักสินสมรสแบ่งให้คู่สมรสคนละส่วนเท่ากัน — ขอให้แบ่ง หรือขายแล้วแบ่งเงิน
**จุดที่ทำให้แพ้:** จัดประเภททรัพย์ผิด (เอาสินส่วนตัวมาขอแบ่ง) / ไม่ระบุรายการทรัพย์ให้ชัด

## 1.6 คดีความสัมพันธ์ระหว่างบิดามารดาและบุตร

- **ฟ้องขอให้รับเด็กเป็นบุตรชอบด้วยกฎหมาย** — บุตรหรือผู้แทนฟ้องให้บิดารับรองความเป็นบิดา
  บรรยายข้อเท็จจริงที่แสดงความเป็นบิดา (หลักตาม ม.1555)
- **จดทะเบียนรับรองบุตร** — บิดาขอจดทะเบียนเด็กเป็นบุตร กรณีมีข้อโต้แย้งต้องดำเนินคดี
- **ฟ้องไม่รับเด็กเป็นบุตร / ปฏิเสธความเป็นบุตร** — มีกำหนดเวลาเฉพาะในการฟ้อง ตรวจให้ดี
- **ถอนอำนาจปกครอง** — กรณีผู้ใช้อำนาจปกครองประพฤติมิชอบหรือใช้อำนาจปกครองโดยมิชอบ

## 1.7 การสมรสที่เป็นโมฆะหรือโมฆียะ

**โมฆะ:** การสมรสที่ฝ่าฝืนเงื่อนไขสำคัญ (เช่น เป็นญาติสืบสายโลหิตโดยตรง สมรสซ้อน คู่สมรส
มิได้ยินยอม) — ผู้มีส่วนได้เสียร้องขอให้ศาลพิพากษาว่าการสมรสเป็นโมฆะ
**โมฆียะ:** การสมรสที่บกพร่องบางประการ (เช่น สำคัญผิดตัว ถูกกลฉ้อฉลหรือข่มขู่ ผู้เยาว์สมรส
โดยไม่ได้รับความยินยอม) — ฟ้องขอเพิกถอนภายในกำหนดเวลา

## 1.8 ร้องขอตั้งผู้ปกครอง / ผู้อนุบาล / ผู้พิทักษ์

- **ผู้ปกครอง** — กรณีผู้เยาว์ไม่มีบิดามารดา หรือบิดามารดาถูกถอนอำนาจปกครอง
- **คนไร้ความสามารถ** (ผู้มีจิตฟั่นเฟือนไม่สมประกอบจนไม่อาจดูแลตนเองได้) — ร้องขอให้ศาลสั่ง
  เป็นคนไร้ความสามารถและตั้ง **ผู้อนุบาล**
- **คนเสมือนไร้ความสามารถ** — ร้องขอให้ศาลสั่งและตั้ง **ผู้พิทักษ์**
**องค์ประกอบที่ต้องบรรยาย:** สถานะของบุคคลที่เกี่ยวข้อง เหตุที่ต้องมีผู้ดูแล ส่วนได้เสีย
ของผู้ร้อง และความเหมาะสมของผู้ที่เสนอให้ตั้ง

## 1.9 คุ้มครองสวัสดิภาพ (ความรุนแรงในครอบครัว)

กรณีมีการกระทำด้วยความรุนแรงในครอบครัว ผู้ถูกกระทำหรือผู้เกี่ยวข้องอาจร้องขอให้ศาลออกคำสั่ง
**คุ้มครองสวัสดิภาพ** (เช่น ห้ามเข้าใกล้ ห้ามกระทำการรบกวน) — มีกฎหมายและกระบวนการเฉพาะ
ที่เน้นความรวดเร็วและความปลอดภัยของผู้ถูกกระทำ

# ส่วน 2 — คดีมรดก

## 2.1 ร้องขอตั้งผู้จัดการมรดก

เป็น **คดีไม่มีข้อพิพาท** เริ่มด้วย **คำร้องขอ** (หลักการตั้งโดยคำสั่งศาลตาม ม.1713)
**องค์ประกอบที่ต้องบรรยาย:** 1) เจ้ามรดกถึงแก่ความตายเมื่อใด ที่ใด (แนบมรณบัตร)
2) ผู้ร้องมีส่วนได้เสียอย่างไร (ทายาท/ผู้มีส่วนได้เสีย) 3) ทายาทของเจ้ามรดกมีใครบ้าง
4) ทรัพย์มรดกพอสังเขป และเหตุขัดข้องในการจัดการ (ต้องโอนทรัพย์ ธนาคารต้องการคำสั่งศาล)
5) เจ้ามรดกทำพินัยกรรมหรือไม่ 6) ผู้ร้องไม่เป็นบุคคลต้องห้ามมิให้เป็นผู้จัดการมรดกและมี
คุณสมบัติครบ
**คำขอ:** ขอให้ศาลมีคำสั่งตั้งผู้ร้องเป็นผู้จัดการมรดกของเจ้ามรดก

## 2.2 ถอนหรือเปลี่ยนผู้จัดการมรดก

**องค์ประกอบที่ต้องบรรยาย:** ผู้จัดการมรดกที่ตั้งไว้ละเลยไม่ทำการตามหน้าที่ จัดการมรดก
โดยมิชอบ ทำให้กองมรดกหรือทายาทเสียหาย หรือมีเหตุอื่นอันสมควร — ผู้มีส่วนได้เสียร้องขอให้
ถอนและตั้งผู้จัดการมรดกคนใหม่

## 2.3 ฟ้องแบ่งมรดก / เรียกทรัพย์มรดก

เป็น **คดีมีข้อพิพาท** เมื่อทายาทตกลงแบ่งกันไม่ได้ หรือผู้ครอบครองทรัพย์ไม่ยอมแบ่ง
**องค์ประกอบที่ต้องบรรยาย:** 1) เจ้ามรดกตายเมื่อใด 2) โจทก์เป็นทายาทประเภทใด (ทายาทโดยธรรม/
ผู้รับพินัยกรรม) และมีสิทธิรับมรดกส่วนใด 3) ทายาทผู้มีสิทธิรับมรดกมีใครบ้างและส่วนแบ่ง
4) ทรัพย์มรดกแต่ละรายการและผู้ใดครอบครอง 5) เหตุที่ฟ้อง — จำเลยครอบครองทรัพย์มรดกไว้
ไม่ยอมแบ่ง
**อายุความมรดก:** สิทธิเรียกร้องของทายาทเกี่ยวกับมรดกมีกำหนดอายุความเฉพาะ (หลักตาม ม.1754
โดยทั่วไป **1 ปี** นับแต่เจ้ามรดกตายหรือนับแต่ทายาทรู้/ควรรู้ถึงสิทธิ และมีกรอบ **10 ปี**
เป็นอย่างช้านับแต่เจ้ามรดกตาย) — **ตรวจและเตือนผู้ใช้เป็นอันดับแรกหากใกล้ขาด**

## 2.4 คดีเกี่ยวกับพินัยกรรม

- **ขอให้พินัยกรรมเป็นโมฆะ/เสียเปล่า** — พินัยกรรมทำผิดแบบที่กฎหมายกำหนด ผู้ทำพินัยกรรม
  ไม่มีความสามารถ ถูกข่มขู่/ฉ้อฉล หรือข้อกำหนดขัดต่อกฎหมาย
- **ฟ้องตามพินัยกรรม** — ผู้รับพินัยกรรมเรียกทรัพย์ตามที่ระบุในพินัยกรรม
- **ตีความพินัยกรรม** — กรณีข้อความในพินัยกรรมไม่ชัดเจน
**ข้อสังเกต:** บรรยายแบบของพินัยกรรม (เขียนเองทั้งฉบับ / มีพยาน / ทำต่อเจ้าพนักงาน ฯลฯ)
และเหตุที่อ้างให้ครบ

## 2.5 การกำจัดและการตัดมิให้รับมรดก

- **กำจัดมิให้รับมรดกฐานเป็นผู้ไม่สมควร** (หลักตาม ม.1606) — ทายาทที่กระทำการบางอย่างต่อ
  เจ้ามรดก (เช่น เจตนากระทำให้เจ้ามรดกถึงแก่ความตายโดยมิชอบ ปลอม/ทำลายพินัยกรรม) อาจถูก
  กำจัดมิให้รับมรดก
- **ตัดมิให้รับมรดก** (หลักตาม ม.1608) — เจ้ามรดกแสดงเจตนาตัดทายาทโดยธรรมมิให้รับมรดกโดย
  ชัดแจ้งตามแบบที่กฎหมายกำหนด

## 2.6 ลำดับทายาทและส่วนแบ่ง (ใช้ประกอบการบรรยายสิทธิ)

**ทายาทโดยธรรม 6 ลำดับ (หลักตาม ม.1629):** (1) ผู้สืบสันดาน (2) บิดามารดา (3) พี่น้องร่วม
บิดามารดาเดียวกัน (4) พี่น้องร่วมบิดาหรือร่วมมารดาเดียวกัน (5) ปู่ย่าตายาย (6) ลุงป้าน้าอา —
ลำดับก่อนตัดลำดับหลัง (โดยมีข้อยกเว้นเรื่องบิดามารดาที่รับร่วมกับผู้สืบสันดาน)
**คู่สมรส:** คู่สมรสที่ชอบด้วยกฎหมายซึ่งยังมีชีวิตอยู่เป็นทายาทโดยธรรม มีส่วนแบ่งร่วมกับ
ทายาทลำดับต่าง ๆ ตามที่กฎหมายกำหนด (หลักตาม ม.1635)
**ข้อสังเกต:** เมื่อมีพินัยกรรม ทรัพย์ส่วนที่พินัยกรรมระบุเป็นไปตามพินัยกรรม ส่วนที่เหลือ
ตกแก่ทายาทโดยธรรม — อย่าสรุปส่วนแบ่งตายตัวจนกว่าจะทราบทายาทและพินัยกรรมครบ

# ส่วน 3 — แม่แบบคำฟ้องและคำร้อง

## 3.1 แม่แบบคำบรรยายฟ้องหย่า

```
        ข้อ 1. โจทก์กับจำเลยเป็นคู่สมรสกันโดยชอบด้วยกฎหมาย จดทะเบียน
        สมรสเมื่อวันที่ .... มีบุตรด้วยกัน .... คน คือ ....

        ข้อ 2. ระหว่างอยู่กินกัน จำเลยได้ [บรรยายข้อเท็จจริงที่เข้า
        เหตุหย่าตามกฎหมาย เรียงตามลำดับเวลา ให้ถึงระดับที่กฎหมายกำหนด]

        ข้อ 3. การกระทำของจำเลยเป็นเหตุให้โจทก์ฟ้องหย่าได้ตามกฎหมาย

        ข้อ 4. [คำขอเรื่องอำนาจปกครองบุตร ค่าอุปการะเลี้ยงดูบุตร
        การแบ่งสินสมรส และค่าทดแทน/ค่าเลี้ยงชีพ ถ้ามี]
```

## 3.2 แม่แบบคำร้องขอตั้งผู้จัดการมรดก

```
        ข้อ 1. นาย/นาง .... เจ้ามรดก ถึงแก่ความตายเมื่อวันที่ ....
        ที่ .... ปรากฏตามมรณบัตรท้ายคำร้อง

        ข้อ 2. ผู้ร้องเป็น [ทายาท/ผู้มีส่วนได้เสีย] ของเจ้ามรดก โดย ....

        ข้อ 3. เจ้ามรดกมีทายาทโดยธรรม คือ .... [และทำพินัยกรรมไว้/
        มิได้ทำพินัยกรรม] มีทรัพย์มรดกได้แก่ ....

        ข้อ 4. การจัดการมรดกมีเหตุขัดข้อง เนื่องจาก .... ผู้ร้องมีความ
        จำเป็นต้องเป็นผู้จัดการมรดก และไม่เป็นบุคคลต้องห้ามมิให้เป็น
        ผู้จัดการมรดกตามกฎหมาย

        ขอศาลได้โปรดมีคำสั่งตั้งผู้ร้องเป็นผู้จัดการมรดกของผู้ตาย
```

# ส่วน 4 — Checklist คดีครอบครัวและมรดก (ตรวจก่อนส่งมอบ)

- [ ] เลือกประเภทเอกสารถูก — "คำร้องขอ" (ไม่มีข้อพิพาท) หรือ "คำฟ้อง" (มีข้อพิพาท)
- [ ] คดีหย่า: ปรับข้อเท็จจริงให้เข้าเหตุหย่าตามกฎหมายและถึงระดับ "ร้ายแรง" ตามที่กำหนด
- [ ] คำขอเรื่องบุตรแสดงว่าเป็นไปเพื่อประโยชน์สูงสุดของบุตร
- [ ] แยกสินส่วนตัวออกจากสินสมรสให้ถูกต้อง ระบุรายการทรัพย์ชัดเจน
- [ ] คดีมรดก: ตรวจอายุความมรดก (โดยทั่วไป 1 ปี / กรอบ 10 ปี) — เตือนหากใกล้ขาด
- [ ] ระบุทายาทและลำดับทายาทให้ครบ ไม่สรุปส่วนแบ่งตายตัวก่อนทราบข้อมูลครบ
- [ ] แนบเอกสารทะเบียนที่จำเป็น (สมรส สูติบัตร มรณบัตร ทะเบียนบ้าน โฉนด พินัยกรรม)
- [ ] ตรวจความสามารถของคู่ความ (ผู้เยาว์ คนไร้/เสมือนไร้ความสามารถ ต้องมีผู้แทน)
- [ ] ใช้ถ้อยคำเป็นกลางทางเพศตามกฎหมายปัจจุบัน
- [ ] ยื่นต่อศาลที่มีเขตอำนาจ (ศาลเยาวชนและครอบครัว ตามแต่ประเภทคดี)
